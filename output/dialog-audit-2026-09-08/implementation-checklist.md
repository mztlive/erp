# Dialog 简化交付与验收清单

## 范围与执行规则

适用范围：erp-client 业务弹窗及调用入口，结算复核候选查询、角色系统属性与对应权限生成物。原扫描清单用于定位，实际交付以当前源码和以下规则为准。

不得绕过审批、岗位分离、幂等、版本冲突或未知结果处理。临时验证页面不得进入交付；当前已删除。

| 编号 | 交付规则 |
| --- | --- |
| D01 | 审批确认只显示必要规则、审批路线和生效结果；普通审批使用正常主按钮，动作风险由调用方明确指定。 |
| D02 | 供给分配预览直接提交；处理中禁止退出；结果未知时使用原请求和幂等标识核对，不得改写本次请求。 |
| D03 | 客户退款、回款冲正、供应商退款和付款冲正在原因弹窗内提交；失败保留输入，结果未知锁定原因；已有草稿入口保留。 |
| D04 | 本地核销分配行直接移除，8 秒内可撤销；撤销恢复金额及原顺序，不写入业务记录。 |
| D05 | 库存调整在同一弹窗展示仓库、SKU、方向、数量、原因及审批信息并提交；未知结果须核对后再处理。 |
| D06 | 结算复核人按姓名和账号搜索选择；候选及提交均须校验有效账号、执行权限、财务责任范围和经办复核分离。 |
| D07 | 验收登记第一步使用“核对验收结果”；最终批次核对保留，默认全通过及不验批次必须明确可见。 |
| D08 | 付款信息、结算金额、订单和核实结果放入“核对信息”；任务版本和内部凭证 ID 不占主内容。 |
| D09 | 连接创建及配置使用任务名称；创建前只提示当前环境；密钥与地址按现有绑定状态区分绑定、更换。 |
| D10 | 健康检查保留确认，并说明更新健康状态及失败产生异常待办；停用只展示连接、环境及影响数量。 |
| D11 | 品牌、分类、计量单位新增省略版本教程，原因使用“创建说明”；更新保留历史版本边界及原因校验。 |
| D12 | 供应商与商品保存保留必要原因、修改摘要及生效时点，删除重复操作说明。 |
| D13 | 首次批量填价直接应用且可撤销；覆盖非空价格和移除 SKU 使用结构化确认；下架及 SKU 停用保留范围说明。 |
| D14 | SKU 编辑说明使用“修改将在保存商品时生效”；完成编辑不得暗示已经保存到服务端。 |
| D15 | 预选 SKU 显示摘要；必填区域及生效日期保持可见；仅物流费用选填区可折叠，有值或错误时展开。 |
| D16 | 审批决定保留真实下一步、金额和节点；通过意见标明可选；驳回、应急代办和取消约束保留。 |
| D17 | 流程创建说明只解释空白或复制来源；发布、退役对新旧单据的实际影响保留。 |
| D18 | 删除文案说明账号登录或角色授权后果；系统角色及绑定系统角色的账号禁用删除入口，服务端校验继续生效。 |
| D19 | 客户及合同新增省略实现说明；客户归属按负责人或协作选择展示对应效果。 |
| D20 | 主体选择按钮使用登记回款、付款及发票的业务名；发票确认展示主体、实际金额、分配笔数和余额，并保留红票纠错说明。 |
| D21 | 导入确认说明本范围试算结果；准备失败项与提交应用保持独立；历史成功项不回滚的规则保留。 |
| D22 | 供应停止与异常任务完成说明不得暗示恢复业务；订单重发、售后请求及结算确认保留实际风险和财务后果。 |
| D23 | 责任配置及转交删除常态权限校验机制说明，保留规则优先级、转交范围及仅影响新任务的边界。 |
| D24 | 纸质预览、未保存保护、冲突处理和有效轻弹窗保持必要结构及可访问名称。 |

## 业务验收要求

真实业务页面的后端请求当前超时。本次浏览器验证使用隔离样例，不构成真实业务提交、审批生效、结算复核候选在线查询或全量页面验收。上线前必须在可用环境执行以下检查：

1. 供给分配只提交一次；模拟超时后，核对请求的业务内容和幂等标识不得改变。
2. 四类退款和冲正分别完成成功、失败、未知结果核对，并检查原单、主体、金额和最终审批记录。
3. 库存调整完成版本冲突、未知结果、审批通过和经办复核分离检查。
4. 结算候选不得包含经办本人、停用账号或权限不足人员；选人后撤销其权限，提交必须失败。
5. 在真实商品和供给入口验证 SKU 损失清单、价格撤销、返回焦点、窄屏滚动以及保存结果。
