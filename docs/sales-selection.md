# 在线选品与询价边界合同

## 1. 在线选品职责

1. 销售通过 `/sales/selection` 维护选品册，客户通过 `/s/{token}` 提交选品结果。客户提交结果保存为销售方案，不自动创建销售单、采购、审批、应收或库存预占。
2. 选品册、公开会话及方案沿用发布时冻结的一件代发报价。不得向客户提供供应商身份、供给身份、集采价及集采起订量。
3. 按份采购方案允许销售主动开单，继承授权客户、冻结商品及数量，成交单价由销售填写；商城兑换方案不按 SKU 转实物与服务销售单。

## 2. Excel 询价职责

1. 客户选品 Excel 和采购往返按[询价业务合同](sales-inquiry-contract.md)执行，使用独立询价身份、需求版本及反馈轮次。
2. 在线选品与询价共用公司 SKU，不复制主档，不覆盖客户已提交的在线选品结果，不复用销售方案身份冒充询价来源。
3. 内部商品池导出保留原有内部用途；询价客户模板必须采用独立白名单，仅含对客商品资料和销售确认的参考价。
4. 两类来源均不自动将参考价作为成交价，不提前决定实际供应商；正式销售、采购与履约继续执行一期基线。
