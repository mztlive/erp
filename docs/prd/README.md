## 阅读规则

- 基线章节描述当前行为，不把行为细节转交给增量 PRD。
- 权限 key、菜单路径、任务类型和状态代码以代码中的稳定标识符为准。
- 发生产品行为变更时，先在 `changes/` 编写增量 PRD；评审通过并实现后，同批更新基线、变更记录和增量 PRD 状态。

## 模块关系

采购责任与一单多采的主流程为：

1. 管理员在基础资料中维护采购责任规则。
2. 销售创建销售单时查看逐行采购负责人预览；外采行无法唯一解析时不能提交审批。
3. 销售单完成全部审批并最终生效后，系统按具体采购负责人建立采购建单任务。
4. 采购从工作台或采购单页面进入，只处理任务冻结范围内仍未覆盖的销售行。
5. 每次创建采购草稿后立即更新销售采购进度；范围剩余归零时任务完成，后续数量重新释放时创建新的开放任务。
