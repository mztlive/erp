版本：V2。登记日期：2026-10-28。验收依据：[批量选品入库执行合同](supplier-api-batch-adoption-contract.md)；设计依据：[页面设计与确认清单](designs/supplier-api-batch-adoption/README.md)。

## 1. 登记与通过条件

1. 本登记覆盖 BA01—BA27。每项只使用“已通过 / 未通过 / 未验证 / 经确认变更”四种结论；部分检查完成时，应列明已取得的证据，并保留整项未完成结论。
2. 代码位置、内联单元测试和静态检查分别登记。源码核对只能证明所列实现入口；编译、lint 或设计图不得作为真实商品写入、权限范围、后台恢复或页面视觉操作通过的证据。
3. 真实页面验收按用户授权使用 computer use 操作本地 ERP，逐项保存实际截图和操作结果。未覆盖的页面状态保持“未验证”；不得将少量草稿操作等同于完整业务验收，不得以模拟数量代替真实执行进度。库测试不得运行依赖真实 MongoDB、S3 或外部供应商的集成测试。
4. 发现实现偏离合同须修复后复验。未经用户明确确认，不得修改验收要求、确认图或原合同以降低通过标准。
5. 执行检查后须记录命令、退出结果及覆盖范围；未执行的检查登记为“未执行”。提交、推送、重启、部署和真实运行验收分别登记。
