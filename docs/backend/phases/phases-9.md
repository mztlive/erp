## 2. 目标与边界

本 phase 只读消费正式事实，负责：

- W15 客户经营质量、风险/贡献指标和可追溯下钻；
- W16 非卡券实际经营盈亏、成本完整性和可靠性标记；
- 提供 W01 所需但不属于正式待办的异步汇总/预警快照；W01 查询 API 仍由 Phase 1 拥有；
- 不超过一分钟的投影水位、每日核对重建和重建审计。

不创建或修改销售、采购、履约、库存、票款、任务或商城事实。正式余额、状态和动作资格
不得从本投影反向写回；正式写命令也不得以本投影代替事务内重验。

依据：`erp-phase-1.md` §4.6.2、§7.5、§9.4；`erp-data-model.md` §9、§12；
W01、W15、W16。

## 4. 输入和查询契约

输入端口只接受不可变事实快照：

- `SalesRevenueSnapshot`、`SalesLifecycleSnapshot`；
- `ReceivableSettlementSnapshot`、`CardFundsReviewSnapshot`；
- `FulfillmentSnapshot`、`ActualCostSnapshot`、`ExceptionSnapshot`；
- `CustomerAssignmentSnapshot`、`PermissionScopeSnapshot`；
- `ProjectionWatermark` / outbox 消费位置。

查询至少返回：统计期间、口径/规则版本、数据水位、可靠性、样本数、权限裁剪结果和可下钻
的稳定对象引用。未知、部分覆盖或策略缺失时返回 `UNAVAILABLE` / `PARTIAL` 和 blocker，
不能用 0 伪装。

## 5. 投影不变量

### 5.1 客户经营质量

- 指标从正式销售、履约、应收、回款、复核和异常事实派生，不接受人工覆盖。
- 销售、经理、财务和管理层使用同一指标算法，但数据范围和字段权限不同。
- 卡券销售单在票款复核未通过时按已确认口径整体排除，不能混入部分可靠金额。
- 风险标签保存规则版本和生效区间；规则变更不回改历史结果。
- 下钻只返回当前权限范围内对象，不因汇总可见而泄露明细或成本。

### 5.2 实际经营盈亏

- 第一期只计算非卡券销售的实际盈亏：不含税收入减实际采购成本和实际履约费用。
- 只使用 `NON_VOUCHER_FULFILLMENT × (ACTUAL | REDUCTION)` 成本；预计/确认成本不冒充实际。
- 卡券直接履约费用可在账上存在，但不得进入卡券实际利润；未覆盖成本不等于零成本。
- 成本不完整、收入口径未确定或数据缺失时标记可靠性，不参与需要完整成本的排名。
- 净收入小于等于零时显示金额，利润率为“不适用”，不参与利润率排名。

### 5.3 水位和重建

- 正式任务、库存、票款同步更新；分析投影允许一分钟内异步刷新。
- 每个投影记录 consumed watermark、规则版本和构建时间。
- 每晚从正式版本、流水、分配和纠错事实全量核对重建；重建失败只影响新鲜度，
  不修改正式事实或旧的最后成功快照。
- 增量投影和全量重建对同一截止水位必须得到一致结果。

## 6. 测试要求

1. 同事实乱序/重复消费、投影水位推进和幂等重建。
2. 客户负责人变化后的数据范围和历史参与者下钻。
3. 卡券票款未复核整体排除，复核后纳入且不补造成本利润。
4. 非卡券不含税利润公式、成本冲减、退款后净收入和利润率不适用。
5. 实际成本缺失、覆盖不全、规则版本缺失返回 PARTIAL/UNAVAILABLE 而非 0。
6. 销售角色查询不包含供应商名称和逐项成本；财务/采购按权限返回。
7. 增量结果与同水位全量重建一致，重建失败不污染正式事实。
8. W01 异步预警与正式待办水位明确分开。

## 7. 未决项与 fail-closed

- W15 Q1：默认统计期间未配置时，首次查询必须显式给 `from/to`。
- W15 Q2：客户标签阈值规则未配置时不输出正式标签。
- W15 Q3～Q5：平均回款周期、票款复核排除粒度、异常范围须以最终指标字典为准；
  当前建议不得静默固化。
- W16 Q1：`periodBasis` 未配置时不返回跨期趋势结论。
- W16 Q2：成本完整性规则缺失时不标记“完整”。
- W16 Q3：返点归类缺失时拒绝由页面选择成本冲减或收入纠错。
- W16 Q4：净收入不大于 0 固定返回利润率不适用；不得除以零或负数排名。
- W16 Q5：销售默认只看授权合计和缺口原因，成本明细需额外权限。

## 8. 完成标准

- 投影只读且可重建，无法反向修改正式事实。
- 客户质量、非卡券利润、水位、可靠性和权限裁剪均有测试。
- 卡券“未覆盖不是零成本”和第一期不算实际利润由类型/测试证明。
- 仅写独占目录，并向 Phase 10 交付输入端口、投影 schema、算法版本、错误码和 blockers。
