## 4. 剩余 blockers / 后端缺口

1. **E3 查询投影未落地**（P5 `feat/erp-e3-projection`）：
   - 工作台汇总 as_of / 预警
   - `/admin/customer-quality`（+ period-policy、exports）
   - `/admin/actual-profit-loss`（+ period-basis、exports、rebuild）
   - `/admin/card-business-analytics`（+ date-basis、exports）
2. work_item 缺少 **hold / team** 范围与队列级 counts 专用接口。
3. work_item 无 **SAVE_EVIDENCE / QUERY_RESULT** 任务内动作。
4. 转交目标需真实用户目录（当前 UI 候选为展示名）。
5. `WorkItemType::is_manually_closable` 当前对全部类型返回 false → 关闭入口始终隐藏（与实体保守默认一致）。

## 5. 集成说明

- 全部请求经 `apiGet`/`apiPost` + TanStack Query；组件内无裸 fetch。
- 金额/数量仅格式化；分析页 as_of 只读接口字段。
- `WorkItemMockError` 名称保留供页面 `instanceof`；实现改为映射 `ApiError`。
- 类型从 mock 迁入 `features/*/types.ts`，owned 页面/辅助 import 已改。
