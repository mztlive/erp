## 6. Remaining blockers / backend gaps

1. **W09 queue projection**: no work_item types for fulfillment; no aggregate queue DTO with gates, source lines, customer labels, remaining qty. Current UI degrades to DRAFT document list.
2. **W09 document create from queue**: posting without an existing draft needs full business keys (purchase_order_id, sales_order_id) not present on rich draft alone for all types.
3. **W09 electronic/service update draft**: create-only + confirm; no PUT body for recipient/location/lines.
4. **W10 availability/q filters & metrics**: server lacks availability filter and reserved/zero aggregates; base unit / movement labels incomplete on list DTOs.
5. **W10 adjustment draft**: update cannot rewrite lines/quantity/note; submit requires `reviewed_by` identity (placeholder used).
6. **W10 export**: no dedicated inventory export endpoint; background job create is a thin stand-in without snapshot freeze of ledger rows.
7. **Live E2E** against running API not executed in this worktree (no backend process assumed).
