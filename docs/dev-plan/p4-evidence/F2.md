## 1. 集成摘要

- `customers`：原先逻辑在 `queries.ts` + `session.ts` + `@/mock/customers`；新建 `api.ts`，用 `apiGet/apiPost/apiPut` 直连 `/admin/customers` 与 `/admin/parties*`。
- `contracts`：原先 `queries.ts` 调 `@/mock/session-state` / `@/mock/contracts`；新建 `api.ts`，直连 `/admin/contracts` 与 `/admin/file-assets/upload`（multipart 原生 fetch + JWT，因 `lib/api` 仅 JSON）。
- 导出函数名保持 queries 可消费：`fetchCustomerDirectory` / `fetchCustomerCenter` / `createCustomer` / `saveCustomerRevision` / `saveCustomerDetails` / `queryCustomerMutationByIdempotency` / `revealCustomerSensitiveField`；`fetchContracts` / `fetchContractCenter` / `fetchContractsForNewSalesOrder` / `uploadContractPdf` / `createContractExportJob`。
- 删除 feature 内 mock 路径：`session.ts`、`erp-client/mock/customers.ts`。
- **保留** `erp-client/mock/session-state.ts` 与 `mock/contracts.ts`（`sales-orders` 等仍引用 W04 session 辅助，不属本批 owns 清理范围）。

## 2. 契约差异表

### 2.1 customers（W03）

| mock / 前端字段或能力 | 后端字段 / 端点 | 处理 |
| --- | --- | --- |
| `CustomerDirectoryItem.legalName` / `ownerName` | 列表 `CustomerView` 无名称；`GET /admin/customers/{id}` 有 `legal_name`/`owner_user_id` | **frontend_adapt**：目录页对每行补拉 detail |
| `scope` mine/collaborating/team | 无 | **backend_gap**：目录统一打全 `scopeTags`，服务端不过滤归属范围 |
| `metrics.*`（在途合同/应收/逾期） | 无客户列表聚合 | **backend_gap**：填 `"0.00"` / `0`，不前端重算 |
| `CustomerCenterView.salesOrders` / `qualitySummary` / `receivableSummary` 明细 | 无本域投影 | **backend_gap**：空数组/零金额；`contracts` 用 `GET /admin/contracts?customer_id=` 填充 |
| 联系人 `phoneMasked` / reveal token | `PartyContactView` 无手机号（仅指纹） | **backend_gap**：展示 `****`，`revealCustomerSensitiveField` → 501 ApiError |
| 地址/银行账户掩码与 reveal | 响应无明文 | **backend_gap**：同上 |
| `CreateCustomerInput.legalName` 等 | 需先 `POST /admin/parties` 再 `POST /admin/customers`（`party_id`+`customer_no`+`owner_user_id`） | **frontend_adapt**：api 内两段创建；`customer_no`/`party_no` 客户端生成 |
| `SaveCustomerRevision` lockVersion on customer | party `version` 与 customer `version` 分离 | **frontend_adapt**：身份修订打 party；冲突比较 customer.version |
| 子资源整表替换（contacts/addresses/banks） | 仅 POST 追加 + 生命周期 PUT | **frontend_adapt**：保存时追加新行；旧行不自动结束（登记） |
| 幂等 `queryCustomerMutationByIdempotency` | 无客户域幂等查询 | **backend_gap**：恒返回 `null` |
| `simulate` demo 开关 | 无 | **frontend_adapt**：忽略；真实 409/OutcomeUnknown 映射为 `conflict`/`unknown` |
| status `active`/`disabled` | `CustomerAccountStatus` snake_case | **already_aligned** |
| 分页 `Page{items,total,page,page_size}` | 同 | **already_aligned**（映射在 api 内） |

### 2.2 contracts（W04）

| mock / 前端字段或能力 | 后端字段 / 端点 | 处理 |
| --- | --- | --- |
| `ContractListRow` 丰富行（客户名、到期标记、销售单数） | `ContractView` 仅 id/编号/客户 id/状态/version | **frontend_adapt**：详情补 revision 快照 + customer brief |
| `expiringWithin30Days` | 无 | **frontend_adapt**：由 `valid_to` 与状态推导（展示筛选用，非金额） |
| `salesOrderCount` / `relatedSalesOrders` | 无合同侧关联投影 | **backend_gap**：`0` / `[]` |
| `auditTimeline` | 无合同审计时间线 API | **backend_gap**：`[]` |
| `ownerLabel` | 无；取客户 `owner_user_id` | **frontend_adapt** |
| `UploadContractPdfInput` 无 `settlement_party_id` | `CreateContractRequest.settlement_party_id` 必填 | **frontend_adapt**：默认客户 `party_id`，或按名称 keyword 查 parties |
| 开票快照 `invoice_type` / `tax_point` | 创建必填 | **frontend_adapt**：默认「增值税专用发票」/「13」（UI 未采集） |
| PDF 上传 | `POST /admin/file-assets/upload` multipart，上限 5 MiB | **frontend_adapt**：原生 fetch；前端仍校验 20 MB 文案 |
| 附件 `securityState` | `security_scan_status` pending/passed/... | **frontend_adapt**：映射 processing/done/quarantined |
| 导出 `createContractExportJob` | 无合同专用导出；尝试 `POST /admin/background-jobs` | **backend_gap**：失败仍返回本地 queued 视图 |
| 状态 EFFECTIVE/TERMINATED/EXPIRED | `ContractStatus` UPPERCASE | **already_aligned** |
| 选择器 `selectableForNewSalesOrder` | 无显式字段 | **frontend_adapt**：`status===EFFECTIVE` 判定 |

## 5. 剩余 blockers / 后端缺口

1. 客户目录 scope（我的/协作/团队）服务端过滤与 metrics 聚合缺失。
2. 敏感字段 reveal 接口缺失（联系人/地址/账号明文不可读回）。
3. 客户写操作幂等查询接口缺失。
4. 联系人/地址/银行账户无「整表替换」语义，编辑态追加可能重复行。
5. 合同关联销售单、审计时间线、导出专用 API 缺失。
6. 合同创建 UI 未采集开票类型/税点；结算主体 ID 未进入 `UploadContractPdfInput` 契约。
7. 文件资产上传 5 MiB 与前端 20 MB 文案不一致。
8. `owner_user_id` 创建依赖 IAM 账号真实存在；演示 DEMO_OWNER_OPTIONS 可能 404。
