## 1. 集成摘要

四个 feature 的 `api.ts` 已从 `@/mock/*` session-mock 改为经 `@/lib/api`（`apiGet` / `apiPost` / `apiPut`）调用真实 `/admin/...` HTTP。导出函数签名与 `queries.ts` 消费方保持稳定；分页 `Page{items,total,page,page_size}` 仅在 `api.ts` 内映射为 feature 视图类型。

- 删除本地 mock 过滤/聚合中与后端重复的部分；后端未提供的筛选/指标在 `api.ts` 内 thrift 组装并登记缺口。
- 金额/数量仅透传字符串并做展示掩码（成本字段），不做运算。
- 错误：HTTP/业务失败由 `ApiError` 传播；角色阻断等客户端前置仍可返回 FormalOutcome `blocked`。
- 不再 import `@/mock/*` 或 `mockDelay`。

## 5. 剩余 blockers / backend gaps（优先）

1. **供应商 API 连接**：无 PENDING_CONFIG、无密钥/地址引用目录、无目录同步触发、无列表 metrics、无采购「业务能力需求确认」、健康检查同步而非后台 job 投影。
2. **供应商商品库**：无队列/changeType 投影、无 publicationImpact、反向创建公司商品无聚合 API、合成 work_item 与真实 work_item 未自动绑定。
3. **商品发布**：修订/列表投影字段偏瘦（缺供给摘要、SKU 编号、完整媒体扫描态）、无安全暂停/发布门闸策略端点、无 metrics 汇总。
4. **执行投影**：白名单缺类目/有效期、无 UNKNOWN 状态、无 latency/reconciliation 服务端投影、无 bulk API、销售单号展示依赖 id。
