## 1. W21 当前合同

W21 只管理公司 SKU 的供应商供给。以下旧能力已经退役，不得恢复：

- 供应商商品/SPU/SKU 主档；
- 供应商商品到公司商品的映射；
- 商品变化队列和同款候选；
- 入池、关联、反向建品；
- `/admin/supplier-catalog/*` 路由。

当前 HTTP 合同：

| 方法 | 路径 | 前端动作 |
| --- | --- | --- |
| `GET` | `/admin/supplier-offerings` | 供给列表与 SKU/供应商筛选 |
| `POST` | `/admin/supplier-offerings` | 添加供给、首版商业条款和初始可供投影 |
| `POST` | `/admin/supplier-offerings/{id}/revisions` | 修订商业条款与关系状态 |
| `POST` | `/admin/supplier-offerings/{id}/availability` | 更新当前可供状态和数量 |

| 权限 | 作用 |
| --- | --- |
| `supplier_offering:list/create/update` | 查询、新增和修订供给 |
