## 2. 契约差异表

### 2.1 procurement-confirmation（W07）

| mock 字段 / 行为 | 后端字段 / 接口 | 处理 |
| --- | --- | --- |
| 队列任务聚合视图 `ProcurementQueueView` | 无专用 queue 投影；`work_items` + `procurement-confirmations` | **frontend_adapt**：组合 work_item 列表与确认详情 |
| `responsibilityScope` mine/role_pool | 无；用 `status=IN_PROGRESS` / `UNCLAIMED` 近似 | **frontend_adapt** + **backend_gap**（无当前用户 owner 过滤） |
| `salesSubmission.*` 完整快照（客户/付款/明细/毛利） | 确认详情仅有 `sales_order_id`/`submission_id`；销售详情 `submissions` 无行明细 | **backend_gap**；尽量读 sales-order 降级填充 |
| `decisionSummary` 覆盖/毛利/阻塞 | 服务端通过时校验覆盖，但 GET 不返回决策摘要 | **backend_gap**；前端占位 `estimatedPurchaseGross="—"`，不重算金额 |
| `confirmation.lines[].supplierName` / `qualificationStatus` / `capabilitySummary` | 仅 `supplier_id` + capability revision id | **backend_gap**；`supplierName=supplier_id`，资质默认 VALID |
| `RejectReasonCode`：`UNFULFILLABLE`/`DELIVERY_UNMET`/`QUALIFICATION_INVALID` | `CANNOT_FULFILL`/`DELIVERY_NOT_MET`/`QUALIFICATION_EXPIRED`/`OTHER` | **frontend_adapt**：发送时映射 |
| `lease` 租约语义 | work_item 原子 claim，无租约到期 | **frontend_adapt** |
| `getTerminalOutcome` | 无 | **backend_gap** |
| `preferences.preferenceScope` | 无 | **backend_gap**；保持 autoNextDefault only |
| 写操作 FormalActionResponse 失败信封 | HTTP 统一信封 + ApiError | **frontend_adapt**：mutation 捕获 ApiError 映射为 `{status:"failed"}` 以保页面契约；claim/save 抛 ApiError |

### 2.2 purchase-orders（W08）

| mock 字段 / 行为 | 后端字段 / 接口 | 处理 |
| --- | --- | --- |
| 状态 `PENDING_REVIEW`/`PARTIAL`/`VOID` | `PENDING_FINANCE_REVIEW`/`PARTIALLY_EXECUTED`/`VOIDED` | **frontend_adapt**：边界双向映射 |
| `salesOrderNo` | 列表/详情仅 `sales_order_id` | **backend_gap**；显示用 id 占位 |
| `ownerName` / `paymentTerm*`（列表） | 列表无 | **backend_gap** |
| `paymentGate` / `prepaymentGate` | 无投影 | **backend_gap**；`NOT_APPLICABLE` |
| `fulfillmentResponsibility`（列表） | 仅详情有 | **backend_gap**（列表默认 WAREHOUSE） |
| `draftEditToken` | 无；乐观锁用 `expected_lock_version` | **frontend_adapt**：客户端生成 `det:{id}:{version}` |
| `draftContentHash` / `expectedDraftContentHash` | 保存/提交无 hash 字段 | **frontend_adapt**：用 `reference` 占位；提交只传 lock_version |
| `SavePurchaseOrderDraft` 行补丁 | 后端整表替换 + 更完整行字段 | **frontend_adapt**：先拉详情再合并 |
| `CreatePurchaseOrderFromBasisInput` 仅 basisId | 需 `purchase_type` + `payment_term_code` | **frontend_adapt**：依据补付款条件；类型默认 PHYSICAL |
| 创建依据 `purchaseType`/`fulfillmentResponsibility`/`salesOrderNo`/`consumed` | 仅 basis 核心字段 | **backend_gap** |
| Metric `gate_blocked` / 复合 fulfill | 无门禁指标；无「待履约」复合筛 | **backend_gap**；gate=0，fulfill≈EFFECTIVE 计数 |
| 排序 `amount`/`source`/`owner` | 白名单 `created_at`/`purchase_no` | **frontend_adapt**：回落 `created_at` |
| `startPurchaseChange.reason` | 必填 | **frontend_adapt**：默认「采购变更」 |
| `reviewWorkItem` / `workflow` / 履约 qty 明细 | 中心视图未返回 | **backend_gap** |
| `queryPurchaseOrderActionResult` | 无 | **backend_gap**；null |
| `payableSummary` | 无 | **backend_gap** |
| 角色成本掩码 `costMasked` | 当前 DTO 恒返回金额 | **backend_gap** / 暂 `false` |
| FormalActionResponse 写结果 | 业务 DTO + HTTP 信封 | **frontend_adapt** |

## 5. 剩余 blockers / 后端缺口（优先）

1. **W07 队列投影**：缺统一 queue DTO（销售提交快照、覆盖决策摘要、责任边界、偏好）。前端组合 work_item+确认详情，字段大量降级。
2. **W07 销售提交行**：`SubmissionView` 无行明细；覆盖编辑依赖确认分行与 working_copy 近似。
3. **W08 `sales_order_no`、owner、列表 payment_term、履约责任**：列表需跨域只读投影。
4. **W08 先款门禁 / payable / workflow / review work_item**：对象中心缺字段。
5. **W08 创建依据**：缺 `purchase_type`、`fulfillment_responsibility`、`sales_order_no`、`consumed`。
6. **draftEditToken / draftContentHash / 幂等结果查询**：前端会话语义后端未提供（乐观锁已有 version）。
7. **指标 `gate_blocked` 与复合待履约筛选**。
8. **本 worktree 无 `node_modules`**：未能跑 `tsc` / `lint`。
