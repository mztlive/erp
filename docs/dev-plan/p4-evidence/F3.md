## 6. 剩余 blockers / 后端缺口

1. **列表视图过瘦**：`SalesOrderView` 缺客户名、合同号、金额、明细、责任人等，W05 列表展示依赖后续投影或详情批量补全。
2. **建单 SKU**：实物行要求 `sku_id`/`sku_revision_id`，前端 `CreateSalesOrderInput` 仅 `sku` 文本。
3. **采购拒绝闭环**：无「改价后重提 / 低毛利申请」专用命令；低毛利任务与 review/work_item 身份耦合不完整。
4. **汇总指标 / origin / summary 筛选**：无服务端支持。
5. **验收草稿**：无 PUT 更新与清除草稿接口。
6. **金额/回款/开票累计**：详情未返回 `receivedAmount`/`invoicedAmount`。
7. **依赖 worktree 无 node_modules**：本地未跑 tsc/lint。
