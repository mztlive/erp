## 1. 集成摘要

- 新建 `erp-client/features/master-data/api.ts`：全部 list / center / create / revise / disable 经 `apiGet` / `apiPost` / `apiPut` 调用 `/admin/...`。
- `queries.ts` 仅作 TanStack Query 薄封装；`queryFn` / `mutationFn` 指向 `api.ts` 导出函数。
- 导出签名保持稳定：`fetchMasterDataList`、`fetchMasterDataCenter`、`createMasterDataObject`、`createMasterDataRevision`、`disableMasterDataObject`、`queryMasterDataIdempotency`、`revealMasterDataSensitive`、`buildMasterDataExportCsv`、`downloadCsv`、`masterDataKeys`、hooks 不变。
- 纯 CSV 工具抽到 `export-csv.ts`。
- 运行时路径不再 `mockDelay`、不再 `@/mock/*`、不再调用本 feature 的 session mock。
- `session.ts` + `data.ts` seeds **暂留**：F9 `supplier-catalog` 仍 `import { buildW14ListResult, createW14Object, getW14Center } from "@/features/master-data/session"`；F9 集成后删除。

## 6. 剩余阻断 / 后端缺口（摘要）

1. 商品/仓库/品牌/分类 **无 GET-by-id**，详情依赖 list 扫描。
2. `ProductView` 缺当前修订嵌入字段（category/brand/description/media/specs）。
3. 规格自由文本 ↔ `sku_attribute` 字典未打通。
4. 敏感字段 reveal API 缺失。
5. 幂等查询 API 缺失。
6. 卡券类目 profile 无 update/disable。
7. 选择器可用性 / 引用数 / 审计 / 权限快照投影缺失。
8. 仓库写责任方未确认（产品要求 fail-closed，前后端一致）。
9. F9 仍依赖 `session.ts` mock；删除需等 F9。
