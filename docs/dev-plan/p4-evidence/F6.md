## 1. 集成摘要

将三个财务 feature 的 runtime 数据路径从 `@/mock/*` / `session-state` 改为 `@/lib/api` 的真实 HTTP（`apiGet` / `apiPost`）。导出函数签名保持稳定，`queries.ts` 钩子形状不变。

| Feature | 主路径 |
| --- | --- |
| customer-receivables | `/admin/receivable-accounts`, `/admin/customer-receipts`, `/admin/invoices`, `/admin/receipt-reversals`, `/admin/customer-refunds` |
| supplier-payables | `/admin/payable-accounts`, `/admin/supplier-payments`, `/admin/purchase-invoice-allocations`, `/admin/payment-reversals`, `/admin/invoices?invoice_direction=purchase` |
| card-funds-review | `/admin/work-items`（`CARD_FUNDS_REVIEW` / `CARD_FUNDS_DELTA_REVIEW`）+ `/admin/receivable-accounts` + `/admin/receivable-funds-reviews` |

核销草稿 session 仍为客户端内存状态（后端无 draft-session 端点）；过账时映射为 create + post 真实调用。
