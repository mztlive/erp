## 1. 集成摘要

五个 feature 的 `api.ts` 已从 `@/mock/*` 改为通过 `@/lib/api`（`apiGet` / `apiPost`）调用真实 `/admin/...` HTTP。  
导出函数签名保持稳定，`queries.ts` 与页面未改业务契约。  
适配（snake_case、秒级时间戳、分页 `Page{items,total,page,page_size}` → 前端 view types）仅在 `api.ts` 内完成。
