## 一、需求背景与目标

一张实物与服务销售单在履约中，经常发生不对应任何销售明细的成本：第三方物流、额外包装、上门安装、加急快递、随单赠品等。这些钱由我方承担，客户不另付，但确实是为这张单花的。

当前流程处理不了这类成本：

1. 采购单只能从供给分配创建，供给分配只处理销售明细的数量缺口。没有对应销售明细的费用，采购无处下单，也就无法形成应付、走付款申请和付款。
2. 采购单上的物流费用只能付给同一采购供应商。第三方物流、外包安装等收款方不是商品供应商时无法登记。
3. 采购物流费用的成本事实没有归属到销售单，也永远不会进入"实际发生"阶段，订单实际经营盈亏漏算这部分费用。
4. 财务按凭证登记成本的能力只有后端接口，没有页面入口。
5. 赠品要发货、要客户验收，但销售明细成交价不能为 0，只能线下处理或虚构价格。

不做的后果：订单利润被系统性高估；附加费用要么在 ERP 外付款，脱离应付和付款审批，要么被塞进商品单价，扭曲采购成本。

成功后：

- 采购可以为销售单追加附加费用采购，付给任意已建档供应商，走正常审批、应付和付款流程；
- 财务可以把 ERP 外已支付的费用按凭证登记到销售单；
- 销售可以在销售单里加 0 元赠品明细，赠品按普通明细选源、履约和验收；
- 订单实际经营盈亏完整计入附加费用；存在尚未确认发生的附加费用时，订单不宣称成本完整。

## 二、目标用户与使用场景

| 角色 | 入口 | 触发时机 | 典型操作 |
| --- | --- | --- | --- |
| 采购 | 销售单详情采购分区"追加附加费用" | 销售单生效后，需要向第三方或商品供应商支付我方承担的费用 | 选供应商、填费用行、保存草稿或提交审批；费用发生后在采购单上"确认发生"并上传凭证 |
| 采购 | 商品采购单编辑、采购改单 | 商品供应商另收费用 | 在同一张采购单上增加费用行 |
| 采购审批人 | 采购审批 | 附加费用采购提交后 | 查看来源销售金额、本单费用及该单已有附加费用合计后决定 |
| 财务 | 销售单详情"附加费用"分区"登记费用" | 费用已在 ERP 外支付（报销、公司卡、平台扣费）或为返点 | 按凭证登记已发生费用；登记错误时登记冲减 |
| 销售 | 销售单新建、销售改单 | 需随单向客户交付赠品、配件或样品 | 添加明细并勾选"赠品"，成交价固定为 0 |
| 财务、管理层 | 实际经营盈亏 | 查看订单利润 | 看到附加费用按类别计入实际履约费用；有未确认发生的附加费用时看到阻断原因 |

前置条件：附加费用只适用于已生效的实物与服务销售单（含已关闭展示态）。卡券销售单沿用 §7.5 由财务直接登记印刷、仓储和配送费用。

异常与权限场景：

- 销售单未生效：不显示"追加附加费用"和"登记费用"入口；
- 收款方未建供应商档案：费用采购单无法选择，提示先建档；
- 无 `cost_entry:list` 权限：销售单详情不展示"附加费用"分区；
- 无采购单查看权限：采购分区不展示费用采购单内容，与商品采购单一致。

## 三、用户可见方案

### 3.1 先分类：哪些不算附加费用

| 情况 | 处理 |
| --- | --- |
| 客户另行付费（定制、加急由客户承担） | 不是附加费用。销售发起改单，添加对应服务明细，按正常销售与采购流程处理 |
| 需要交付给客户的物品（赠品、配件、样品） | 不是附加费用。作为**赠品明细**加入销售单，见 3.2 |
| 我方承担、无交付对象的成本 | **附加费用**。需要通过 ERP 向收款方付款的走**费用采购单或商品采购单费用行**（3.3），ERP 外已支付或无需付款的由**财务登记**（3.4） |

### 3.2 赠品明细

1. 销售新建和改单时，明细可勾选"赠品"。赠品明细从公司商品池选择，成交价固定为 0 且不可编辑，数量、交付期限、服务地区和分地址交付照常填写。
2. 只有赠品明细允许成交价为 0；非赠品明细仍须大于 0。
3. 赠品标记随稳定明细固定：改单时不得把已有明细在赠品与非赠品之间切换，需要切换时把原明细数量归零并新增明细。
4. 赠品明细在销售单、审批材料、采购单关联销售资料和客户验收中标记"赠品"。毛利估算照常计入赠品的估算成本，收入为 0。
5. 赠品明细与普通明细一样进入供给分配、采购、履约和客户验收，计入履约进度和销售单关闭条件。
6. 赠品明细不形成应收，不进入可开票金额。
7. 实际经营盈亏中赠品明细收入为 0，实际供货成本照常计入，并与普通明细一样参与成本覆盖判定。

### 3.3 费用采购

**费用行**：现有"物流费用"扩为通用费用行。费用行包含费用类别、费用说明、含税金额、进项税率、不含税金额、税额、归属销售明细（可选）和预计发生日（可选），不带商品、数量和单价。

- 费用类别：物流、印刷、仓储、配送、平台技术、线下服务、其他。存量物流费用行按"物流"类别展示。
- 归属销售明细只能选择来源销售当前生效版本中数量大于 0 的明细；不选时归属整张销售单。

**两种承载方式**：

| 方式 | 适用 | 规则 |
| --- | --- | --- |
| 商品采购单上的费用行 | 收款方就是该采购单的商品供应商 | 随商品采购单创建、审批、改单；一件代发采购价已包含发货、包装等费用，不得重复登记物流费用 |
| 费用采购单 | 收款方是任意已建档、启用的供应商，包括非商品供应商 | 从销售单详情"追加附加费用"创建，只含费用行 |

**费用采购单流程**：

1. 采购在已生效销售单详情点"追加附加费用"，选择供应商、付款条件，填写一行或多行费用行，可上传报价或账单附件。我方付款主体继承来源销售版本的结算主体。
2. 费用采购单不经过供给分配，不选择供应商供给，不计入销售明细的供给覆盖。采购类型显示为"费用"，没有履约责任，不生成入库、发货、电子交付或服务履约任务。
3. 可以保存草稿，确认后提交审批。审批沿用采购单已发布审批定义，撤回、驳回后修改原单、作废草稿等规则与普通采购单相同。
4. 审批材料展示来源销售单号、客户、销售含税金额、本单费用明细，以及该销售单已生效附加费用合计（含本单）。
5. 生效后形成应付；付款申请、付款、进项发票与普通采购单相同。先款门槛不关联发货。
6. 采购列表可按采购类型"费用"筛选；销售单详情采购分区与商品采购单并列展示费用采购单。

**确认发生**（费用采购单与商品采购单费用行通用）：

1. 采购单生效后，采购负责人在费用行上点"确认发生"，填写发生日期并上传凭证（运单、签收单、服务完成记录或收款方账单），可多行一并确认。
2. 每行只能确认一次，确认后该行显示"已发生"并锁定。
3. 未确认的费用行显示"待发生"。

**改单与作废**：

1. 已生效采购单可通过采购改单调整**未确认发生**费用行的金额、税率、说明和归属明细，或移除该行（金额归零）。已确认发生的费用行不可修改；多付金额通过供应商退款处理并形成成本冲减。
2. 采购改单不能新增费用行；新的费用另建费用采购单。商品采购单改单原有规则不变。
3. 改后含税总额不得低于已付款和已收票金额（沿用现有规则）。
4. 费用采购单草稿可作废，审批中须先撤回。

### 3.4 财务登记附加费用

1. 财务在已生效销售单详情"附加费用"分区点"登记费用"，填写费用类别（含"返点"）、费用说明、含税金额、税率、发生日期、供应商（可选）、归属销售明细（可选），并上传凭证（必填）。
2. 登记即为"实际发生"，不形成应付，不进入付款申请。
3. 通过 ERP 付款的费用必须走 3.3 的费用采购，不得由财务再登记一次。登记弹窗列出该销售单已有附加费用，供财务比对。
4. 已登记费用不可修改或删除；登记错误时登记冲减，冲减金额不超过原费用尚未冲减的金额。

### 3.5 销售单详情"附加费用"分区

- 对具备 `cost_entry:list` 的账号展示；
- 逐笔列出来源（费用采购单号、商品采购单号或财务登记）、类别、说明、含税与不含税金额、阶段（已确认 / 已发生 / 冲减）、归属明细和发生日期；
- 汇总显示"待发生合计"和"已发生合计"；
- 归属明细已在后续销售版本中数量归零的，保留原归属并标注"明细已移除"。

### 3.6 成本口径

| 来源 | 已确认 | 实际发生 | 冲减 |
| --- | --- | --- | --- |
| 费用行（费用采购单或商品采购单） | 采购单生效或采购改单生效时 | 确认发生时 | 供应商退款时 |
| 财务登记 | — | 登记时 | 登记冲减时 |

- 每笔附加费用归属到来源销售单；选择了归属明细的同时归属到该明细。
- 已确认阶段计入执行过程中的预计盈亏；实际发生和冲减计入实际经营盈亏的"实际履约费用"，按费用类别展示构成。
- 附加费用不改变"每条销售明细须有实际供货成本"的覆盖判定。
- 销售单存在已生效、未确认发生且未移除的费用行时，实际经营盈亏显示阻断原因"附加费用待确认发生"，该单收入不计入成本覆盖收入。

## 四、边界与非目标

1. 不做跨多张销售单分摊的公共费用（如月度仓储费按订单分摊）。一笔附加费用只归属一张销售单，需要分摊时由财务分别登记。
2. 附加费用不向客户转嫁，不生成应收，不进入开票额度。
3. 不改变第 4.4.1 节毛利估算口径；毛利估算不扣减附加费用。
4. 不做费用预算、额度或毛利阈值控制；是否批准由采购审批人判断。
5. 不自动识别重复登记。
6. 卡券销售单不支持费用采购单和赠品明细。
7. 附加费用不参与第 6.3 节"销售变更对采购的影响"判定；销售变更不会自动撤回、标记或调整费用采购单。
8. 不新增菜单、通知或后台任务。
9. 本期 ERP 不计算赠品视同销售的销项税额（见开放问题 1）。

## 五、验收标准

**赠品明细**

1. Given 销售新建实物与服务销售单，When 添加明细并勾选"赠品"，Then 成交价显示 0 且不可编辑，保存成功；未勾选赠品的明细填 0 时提示"含税单价须大于0"。
2. Given 含赠品明细的销售单生效，When 采购查询供给分配依据，Then 赠品明细与普通明细一样出现在待分配列表并可分配库存或采购。
3. Given 含赠品明细的销售单，When 查看应收和可开票金额，Then 赠品明细不贡献任何金额。
4. Given 已生效销售单的一条赠品明细，When 销售发起改单并尝试取消赠品标记，Then 不允许修改，提示归零原明细后新增。
5. Given 赠品明细尚未客户验收，When 其他明细全部验收且应收结清，Then 销售单不关闭。

**费用采购**

6. Given 已生效实物与服务销售单，When 采购点"追加附加费用"，选择非商品供应商的已建档供应商并填写两行费用后提交，Then 生成采购类型为"费用"的采购单并进入采购审批，销售明细的覆盖数量不变。
7. Given 销售单未生效或为卡券销售单，Then 不显示"追加附加费用"入口，直接调用被拒绝。
8. Given 费用采购单审批中，When 审批人打开审批材料，Then 能看到来源销售单号、客户、销售含税金额、本单费用明细和该销售单已生效附加费用合计。
9. Given 费用采购单生效，Then 形成等额应付，可纳入付款申请；不生成任何入库、发货、电子交付或服务履约待办。
10. Given 生效的费用行，When 采购负责人确认发生但未上传凭证，Then 拒绝；上传凭证后该行显示"已发生"且不可再次确认。
11. Given 已确认发生的费用行，When 采购发起改单修改其金额，Then 拒绝；未确认发生的费用行可改金额或移除。
12. Given 商品采购单，When 采购在其上增加一行类别为"其他"的费用行并生效，Then 该行收款方即该商品供应商，该费用以"已确认"阶段出现在销售单"附加费用"分区。

**财务登记**

13. Given 具备 `cost_entry:create` 的财务，When 在销售单详情登记一笔快递费并上传凭证，Then 该费用以"已发生"阶段出现在"附加费用"分区和实际经营盈亏的实际履约费用中，不产生应付。
14. Given 未上传凭证，Then 登记被拒绝。
15. Given 已登记费用，When 财务登记冲减超过原费用剩余金额，Then 拒绝。

**盈亏口径**

16. Given 销售单全部明细已有实际供货成本且履约完成，When 存在已生效但未确认发生的费用行，Then 实际经营盈亏显示"附加费用待确认发生"，该单不计入成本覆盖收入；确认发生或移除后阻断解除。
17. Given 商品采购单上的物流费用行确认发生，Then 订单实际经营盈亏的物流费用构成增加该行不含税金额。
18. Given 无 `cost_entry:list` 的销售账号，When 打开销售单详情，Then 不显示"附加费用"分区。

## 六、方案与取舍

**为什么复用采购单承载附加费用，而不新建"附加费用单"**：附加费用需要应付、付款申请、付款、进项发票和审批，这条链路采购单已完整具备。新建单据意味着复制整条票款链路和权限。代价是采购单要容纳"无履约、无供给"的类型，需在类型、列表和详情上做区分。

**为什么赠品用 0 元销售明细，而不是附加费用**：赠品要选源、发货、验收，这些能力都以销售明细为单位。挂在费用上无法发货和验收。代价是要放开"非卡券明细成交价必须大于 0"，以赠品标记约束。

**为什么"确认发生"统一手工确认，而不在商品采购履约完成时自动转为实际**：费用的发生时点与商品交付不一定一致（运费可能先付后发、安装可能晚于到货），且费用采购单没有履约事件可挂。统一手工确认规则一致、可附凭证。代价是采购多一步操作，用"附加费用待确认发生"阻断原因兜底防遗漏。

**对既有规则的澄清（需评审确认，不视为推翻）**：

| 原文（§7.4） | 本方案后的含义 |
| --- | --- |
| "供给分配是唯一选源环节" | 仍是销售明细供给覆盖的唯一选源环节；附加费用采购不是选源，不受此限 |
| "采购单创建成功即提交审批，不得留下未提交草稿" | 只约束供给分配创建的采购单；费用采购单允许保存草稿 |
| "物流费用支付给同一采购供应商" | 商品采购单上的费用行仍付给该供应商；其他收款方另建费用采购单 |
| "实际经营盈亏只使用实际发生和冲减成本"（§7.5） | 不变；新增"附加费用待确认发生"阻断，防止漏记费用被当作利润 |

### §4.4.4 赠品明细（新增）

1. 实物与服务销售单新建和改单时，明细可标记为赠品。赠品明细从公司商品池选择，含税成交单价固定为 0；只有赠品明细允许成交价为 0。
2. 赠品标记随稳定明细固定；改单时不得切换，需要切换时将原明细数量归零并新增明细。
3. 赠品明细在销售单、审批材料、采购单关联销售资料和客户验收中标记"赠品"。毛利估算计入其估算成本，收入为 0。
4. 赠品明细按普通明细进入供给分配、采购、履约和客户验收，计入履约进度和销售单关闭条件；不形成应收，不进入可开票金额。
5. 实际经营盈亏中赠品明细收入为 0，实际供货成本照常计入并参与成本覆盖判定。
6. 卡券销售单不支持赠品明细。

### §7.4 供给分配与采购单规则（修改）

- 商品供应商另外收取的费用，在同一张采购单中增加费用行；收款方不是该采购单供应商的费用另建费用采购单；
- 商品成本和费用分别记录金额、税率、税额和不含税金额；
- 费用行规则、确认发生和成本口径见第 7.5.1 节。

### §7.5.1 附加费用（新增，置于 §7.5 金额计算规则之后）

**分类**

- 客户另行付费的事项不是附加费用，由销售改单添加对应服务明细；
- 需要交付给客户的物品不是附加费用，按第 4.4.4 节作为赠品明细；
- 我方承担、无交付对象的成本是附加费用。通过 ERP 付款的以费用行承载；ERP 外已支付或无需付款的由财务登记。同一笔费用不得两处重复登记。

**费用行**

- 费用行记录费用类别、费用说明、含税金额、进项税率、税额、不含税金额、归属销售明细（可选）和预计发生日（可选），不带商品、数量和单价；
- 费用类别为物流、印刷、仓储、配送、平台技术、线下服务和其他；
- 归属销售明细只能选择来源销售当前生效版本中数量大于 0 的明细，不选时归属整张销售单；
- 费用行可在商品采购单上增加（收款方为该供应商），也可组成费用采购单。

**费用采购单**

- 仅限已生效的实物与服务销售单，从销售单详情追加创建，包括已关闭展示态；
- 供应商为任一已建档且启用的供应商；我方付款主体继承来源销售版本的结算主体；
- 不经过供给分配，不选择供应商供给，没有履约责任，不生成履约任务，不计入供给覆盖；
- 可保存草稿；审批沿用采购单已发布审批定义及其撤回、驳回和修改原单规则；审批材料展示来源销售单号、客户、销售含税金额、本单费用明细和该销售单已生效附加费用合计；
- 生效形成应付，付款申请、付款和进项发票按普通采购单执行；先款门槛不关联发货；
- 采购改单只能调整或移除未确认发生的费用行，不能新增费用行。

**确认发生**

- 采购单生效后，采购负责人逐行确认费用发生，填写发生日期并上传凭证；每行只能确认一次，确认后锁定；
- 已确认发生的费用多付时，通过供应商退款处理并形成成本冲减。

**财务登记**

- 财务按凭证登记附加费用，填写费用类别（另含返点）、说明、含税金额、税率、发生日期、供应商（可选）、归属销售明细（可选）和凭证（必填）；
- 登记即为实际发生，不形成应付，不进入付款申请；
- 已登记费用不可修改或删除；错误时登记冲减，冲减金额不超过原费用尚未冲减金额。

**成本口径**

- 费用行在采购单或采购改单生效时形成已确认成本，确认发生时形成实际发生成本，供应商退款时形成冲减；财务登记直接形成实际发生成本；
- 每笔附加费用归属到来源销售单，选择了归属明细的同时归属到该明细；
- 实际发生和冲减计入"实际履约费用"，按费用类别展示构成；已确认计入预计盈亏；
- 附加费用不改变销售明细的成本覆盖判定；销售单存在已生效、未确认发生且未移除的费用行时，实际经营盈亏显示"附加费用待确认发生"，该单收入不计入成本覆盖收入；
- 一笔附加费用只归属一张销售单，不做跨单分摊。

**可见性**

- 销售单详情"附加费用"分区对具备 `cost_entry:list` 的账号展示，逐笔列出来源、类别、说明、金额、阶段、归属明细和发生日期，汇总待发生与已发生金额；
- 费用采购单的可见性与普通采购单相同。

- 财务：追加"ERP 外已支付附加费用的凭证登记与冲减"。

## 九、开放问题

1. **赠品视同销售的税务处理**（待财务确认）：无偿赠送货物在增值税上通常视同销售。本方案 ERP 不计算赠品视同销售销项税额，只标记赠品，由财务线下处理。是否接受？
2. **费用采购单是否需要独立审批定义**（待确认）：本方案沿用采购单审批定义。如需对附加费用增加销售领导或财务节点，需要新增审批类型或条件分支。
3. **未确认发生的费用阻断成本覆盖**（待确认）：本方案选择阻断，宁可不报利润也不高估。若认为过严，可改为仅提示不阻断。
4. **存量物流费用成本事实**（待确认）：现有已确认物流成本未归属销售单。建议沿用此前切换策略，不迁移、不兼容旧数据，业务数据按正式流程重建。
5. **确认发生权限动作命名**（待实现确认）：拟定 `purchase_order:confirm_expense`。

### 与本文方案的差异（已按实现写入基线）

1. 费用采购单创建即提交审批，不保存草稿；撤回或驳回后只能修改费用金额和进项税率。
2. 本期不在商品采购单上新增费用行，商品供应商另收的费用也另建费用采购单。存量商品采购单上的物流费用行（无费用内容）不进入确认发生与盈亏，按开放问题 4 不迁移。
3. 费用行不记录预计发生日。
4. 采购改单只开放未确认发生费用行的含税金额和进项税率；金额改为 0 即移除，说明和归属明细不改。
5. 费用行在采购生效时的已确认成本不归属销售单，不进入预计盈亏，也不随采购改单生成差额；只有确认发生和财务登记、冲减计入销售单。
6. 后付或周期结算的费用采购单以采购生效日作为应付基准日。
7. 已确认发生的费用行多付时，供应商退款不自动生成成本冲减。
8. 赠品标记只在销售单详情展示；审批材料、采购关联销售资料、客户验收按成交单价 0 展示。
9. 费用采购审批材料的数量合计冻结为 0（审批引擎要求采购单携带数量）。
