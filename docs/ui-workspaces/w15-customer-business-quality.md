# W15 · 客户经营质量

> 状态：已定
> 页面模式：M6 只读分析
> 主要路由：`/analytics/customer-quality`
> 主要角色：管理层、销售、销售经理、财务
> 最后更新：2026-08-01

## 1. 定位与目标

### 1.1 用户目标

用户按统计期间和授权范围判断客户的业务规模、结构、利润贡献、回款风险、异常情况和合作连续性，并从指标直接下钻到形成结论的正式业务对象。

进入页面后应能回答：

1. 哪些客户贡献规模和利润，哪些客户低利润或亏损？
2. 哪些客户存在逾期、账龄或回款周期风险？
3. 当前结论覆盖了多少真实成本与已复核卡券票款，哪些指标暂时不能可靠判断？
4. 点击某个指标后，哪些销售单、应收或异常事实形成了这个结果？

### 1.2 业务目标

- 从销售、履约、票款、成本和异常正式事实形成可重建的客户经营质量投影。
- 同屏展示业务规模、实际利润贡献、成本覆盖和应收质量，避免用单一销售额代表客户价值。
- 把卡券票款复核不足与成本未覆盖明确暴露，禁止用不完整数据生成误导结论。
- 让销售只看负责客户、销售经理看团队、财务和管理层按授权看公司范围。
- 所有经营标签必须按带生效日期的年度服务端规则版本生成；页面必须展示规则版本；禁止页面人工改标签、改统计值或回改历史结果。

### 1.3 不在本工作面完成

- 不维护客户基础资料、销售归属或联系人；进入 W03。
- 不登记回款、发票或核销；进入 W11。
- 不修改销售单、成本事实、退货、退款或异常；进入其原对象工作面。
- 不把卡券缺失的实际供货成本按 0 计算利润；卡券消费经营分析进入 W28。
- 不提供“调整经营质量分”“手工标记重点客户”等覆盖固定规则的操作。

## 2. 用户、权限与数据范围

| 角色 | 默认入口 | 可见范围 | 主要动作 |
| --- | --- | --- | --- |
| 销售 | 从 W01 / W03 进入 | 当前负责或协作客户；历史参与单据按权限保留 | 查看客户表现、下钻本人有权对象 |
| 销售经理 | W15 | 当前团队负责客户 | 比较客户、定位回款与低利润风险、下钻团队对象 |
| 财务 | W15 | 授权公司或组织范围 | 查看票款、成本覆盖、实际利润与复核进度 |
| 管理层 | 经营默认着陆 | 授权公司汇总及客户明细 | 查看全局趋势、客户构成和风险；无编辑入口 |
| 系统管理员 | 无业务默认入口 | 仅投影运行状态和技术元数据 | 重建排障；不得改指标或标签 |

权限规则：

- 无 W15 模块权限时隐藏入口；直接访问显示无权限页。
- 数据范围由服务端应用于汇总、图表和明细，三者必须使用同一权限/范围版本。
- 无任何客户数据范围时显示专用空态，不把公司级指标显示为 0。
- 销售无权查看的客户、销售单和应收不得通过排行、tooltip、导出或总数反推出信息。
- 成本、利润、税务和逾期明细可按字段权限分别控制；隐藏时保留指标位置并说明“当前角色不可查看”。
- 权限在页面打开期间收回时清除缓存中的敏感明细，汇总与下钻同步切换权限态。

- 指标单击只在当前分析页改变下钻维度或过滤，不直接执行业务动作。
- 图表选择必须同步更新明细表，并显示当前筛选摘要与结果数量。
- 客户身份、逾期应收和实际盈亏分别进入 W03、W11、W16；不在 W15 嵌入编辑器。
- 图表必须提供等价表格/列表，不把颜色或鼠标 hover 作为唯一读数方式。

## 5. 展示内容与字段

### 5.1 页头、覆盖与指标

| 区域 | 字段 | 用户文案 | 数据来源 | 口径 / 格式 | 权限规则 |
| --- | --- | --- | --- | --- | --- |
| 页头 | `projectionUpdatedAt` | 数据更新时间 | 经营质量统计更新时间 | 绝对时间 + fresh/stale/rebuilding/failed | 全部有权用户 |
| 覆盖 | `cardFundsReviewRate` | 卡券票款复核进度 | W13 复核事实投影 | 已复核正式卡券单 / 应复核正式卡券单 | 无票款字段权时仅显示覆盖等级 |
| 覆盖 | `costCoverageRate` | 成本覆盖率 | 服务端经营投影 | 成本覆盖收入 / 适用收入；分子分母同口径 | 有利润权限 |
| 指标 | `salesGrossAmount` | 成交金额（含税） | 生效销售版本 | 卡券 + 非卡券；按所选期间口径 | 有销售金额权限 |
| 指标 | `salesOrderCount` | 销售单数 | 生效销售单 | 去重稳定销售单 | 全部有权用户 |
| 指标 | `coveredNonVoucherNetRevenue` | 成本完整非卡券收入（不含税） | 销售 + 成本覆盖投影 | 只含非卡券，不混卡券收入 | 有利润权限 |
| 指标 | `actualProfitLossNet` | 实际经营盈亏（不含税） | W16 同口径投影 | 非卡券净收入 − ACTUAL/REDUCTION 净成本 | 有利润权限 |
| 指标 | `receivableOpenGross` | 应收余额（含税） | 应收开放余额 | 卡券复核不足时必须同屏警示 | 有票款权限 |
| 指标 | `overdueGross` | 逾期金额（含税） | 应收账龄投影 | 按服务端到期日和业务时区 | 有票款权限 |
| 指标 | `averageCollectionDays` | 平均回款周期 | 回款/核销事实 | 服务端必须按已结清应收金额加权；必须同屏展示样本数；禁止按笔数简单平均 | 有票款权限 |
| 指标 | `exceptionCustomerCount` | 有异常客户 | 正式异常/纠错对象与高风险待办 | 期间内至少一项已形成正式异常/纠错对象或高风险待办；禁止将普通协同提醒或处理中的普通任务计入 | 按异常对象权限 |

### 5.2 构成与标签

| 内容 | 数据来源 | 展示规则 | 明确排除 |
| --- | --- | --- | --- |
| 业务规模分层 | 服务端年度规则版本（含生效日期） | 重点 / 正常 / 低规模；必须展示规则版本；历史结果按当时生效版本保留，禁止回改 | 不允许人工改标签 |
| 福利场景构成 | 销售单明细 | 年节礼包、餐补、慰问品、消费金、其他 | 未授权销售事实 |
| 销售性质构成 | 销售单 | 卡券、实物商品、虚拟商品、线下服务 | 不把创建系统当业务类型 |
| 利润贡献标签 | 成本完整非卡券经营投影；年度规则版本 | 高贡献 / 正常 / 低利润 / 亏损；必须展示规则版本；禁止回改历史结果 | 卡券收入和未覆盖成本不进入利润标签 |
| 回款风险标签 | 应收、逾期、账龄、回款周期；年度规则版本 | 正常 / 关注 / 逾期 / 高风险；必须展示规则版本；禁止回改历史结果 | 未复核卡券票款不得假装可靠 |
| 合作与复购 | 销售单历史 | 连续合作时间、最近业务时间、复购次数/间隔 | 不由前端当前页行数推导 |

## 6. 搜索、筛选、排序与默认视图

| 能力 | 默认值 | URL 状态 | 行为 |
| --- | --- | --- | --- |
| 统计期间 | 服务端版本化 `customerQualityPeriodPolicyId/version` 配置的默认期间；缺失时无默认值 | `from/to`；用户选快捷项时可附 `periodPreset` | 所有指标、图表、表格使用同一明确期间；缺配置且 URL 无 `from/to` 时首次分析必须先选择起止日期；禁止静默采用自然年、滚动 12 个月或财年作为隐式回退 |
| 数据范围 | 当前角色默认范围 | 固定为角色默认范围，不接受 URL 覆盖 | 销售=本人，经理=团队，管理/财务=授权公司范围 |
| 票款口径 | 全部授权事实 | `fundsReview=all` | 卡券复核不足时警示；可切“仅统计已复核数据”。`fundsReview=reviewed_only` 时必须按销售单复核状态整单纳入或整单排除；禁止仅排除未确认的回款/开票部分而保留同单部分可靠数据 |
| 业务性质 | 全部 | `businessType` | 卡券 / 非卡券；选择卡券时隐藏实际盈亏并解释 |
| 福利场景 | 全部 | `benefitScenario` | 影响规模和构成，不改变正式事实 |
| 标签 | 全部 | `scaleTag`、`profitTag`、`riskTag` | 标签必须来自带生效日期的年度规则版本；页面必须展示版本；禁止回改历史结果 |
| 搜索 | 空 | `q` | 客户编号、名称精确/前缀搜索 |
| 排序 | 成交金额降序 | `sort` | 顶部「排序」下拉与表头排序同源（同一 `sort` 参数）；表头点击回写 URL，服务端排序作用于全量结果，不只当前页；可按实际盈亏、逾期、覆盖率、最近业务排序 |
| 明细页 | 20 行 | `page`/`pageSize` | 服务端分页（服务端返回当前页行集与过滤总数）；图表汇总不由当前页求和 |

筛选改变时保留旧图表并显示轻量刷新，结果标题通过 `aria-live=polite` 播报。业务性质为卡券时，利润指标区改为“卡券实际经营结果请前往 W28”，不得显示 ¥0 或无穷大利润率。

`periodPreset` 仅是已配置快捷项的 URL 提示；路由层必须通过服务端 `customerQualityPeriodPolicyId/version` 将其归一化为明确 `from/to` 并写回 URL。若 URL 没有 `from/to` 且服务端没有有效默认期间，页面显示期间选择 blocker，不发起分析查询，也不静默回退到本自然年。查询与跨 W 下钻只使用已解析的 `from/to`，不传含义不稳定的另一套 `period` 参数。

## 7. 操作契约

W15 没有修改业务事实或分析口径的提交动作。

| 操作 | 入口 | 权限 / 前置条件 | 确认 | 成功结果 | 失败恢复 |
| --- | --- | --- | --- | --- | --- |
| 切换期间/范围 | 页头筛选 | 有对应数据范围 | 无 | 同步更新 URL、指标、图表和表格 | 请求失败恢复原筛选与旧数据 |
| 仅看已复核 | 覆盖提示 / 筛选 | 有票款口径查看权 | 无 | 按销售单复核状态整单过滤后重查所有应收相关指标，并明确样本范围；不得按回款/开票行部分过滤 | 保留原结果并提示失败 |
| 选择指标/图表 | 指标或图表 | 对应字段可见 | 无 | 更新下钻筛选和明细表 | 失败保持上一选中态 |
| 打开客户 | 明细行 | 有 W03 对象权限 | 无 | 新页签打开客户中心 | 无权限时原位说明，不泄露对象内容 |
| 打开逾期应收 | 指标 / 单元格 | 有 W11 权限 | 无 | W11 带客户、期间和逾期筛选 | 返回恢复原行焦点 |
| 打开实际盈亏 | 指标 / 单元格 | 有 W16 权限 | 无 | W16 使用同一期间口径 | 无权限则不展示入口 |
| 导出分析 | 页头 | `EXPORT`；字段和范围已授权 | 显示期间、口径、覆盖率和行数 | 后台生成带口径说明和更新时间的 7 天文件 | 任务失败可重试；不回退为无更新信息即时下载 |
| 刷新 | 页头 | W15 可访问 | 无 | 请求投影最新更新时间 | 保留旧结果并标记刷新失败 |

不得出现“编辑指标”“修改标签”“手工补利润”等操作。发现源事实有误时，用户下钻原对象并按正式变更、冲正或纠错流程处理，W15 等待投影刷新。

```ts
    costUncoveredNetRevenue: string
    costCoverageRate: string
  }
  metrics: Array<{
    key: string
    label: string
    value: string
    amountBasis?: "GROSS" | "NET"
    visible: boolean
    reliability: "reliable" | "partial" | "unavailable"
    explanation?: string
  }>
  dimensions: Array<{
    key: string
    ruleVersion?: string
    items: Array<{ code: string; label: string; value: string; share?: string }>
  }>
  customers: {
    items: CustomerQualityRow[]
    nextCursor?: string
    total: number
  }
}

type CustomerQualityRow = {
  customerId: string
  customerNo: string
  customerName: string
  ownerLabels: string[]
  tags: Array<{ type: "scale" | "profit" | "risk"; code: string; label: string }>
  salesGrossAmount: string
  salesOrderCount: number
  voucherShare: string
  costCoveredNetRevenue: string
  costUncoveredNetRevenue: string
  costCoverageRate: string
  actualProfitLossNet?: string
  marginRate?: string
  receivableOpenGross?: string
  overdueGross?: string
  averageCollectionDays?: string

  latestBusinessAt?: string

}
```

- 首次进入先查询服务端期间配置；只有取得有效默认 `from/to`，或用户显式选择 `from/to` 后，才构造 `CustomerQualityQuery`。缺配置不是空数据态，而是阻止分析查询的“请选择统计期间”状态。
- 查询由 TanStack Query 管理；Query Key 包含明确期间、适用时的期间策略 ID/版本、期间口径、范围/权限版本、复核口径及全部筛选。
- 指标和维度来自服务端完整范围聚合，不从当前客户分页求和。
- 经营质量投影允许异步延迟不超过 1 分钟，并保存来源消息消费位置；页面必须展示数据更新时间。
- 服务端每天从正式版本、票款、履约、成本与异常事实核对并重建；重建不改正式事实。

### 8.2 提交

W15 无业务 mutation。以下行为都属于查询状态：期间切换、筛选、图表选择和下钻。

导出只提交一个后台导出任务，命令包含查询快照、权限/数据范围版本、口径版本、投影更新时间和用途；导出任务不得改变经营标签或业务事实。

### 8.3 前端边界

- 前端只格式化金额、百分比、时间、标签 tone 和图表坐标。
- 前端可计算纯展示的 tooltip 比例校验，但不得替代服务端汇总或写回。
- 成交金额、实际盈亏、利润率、成本覆盖、应收、账龄、回款周期、标签和复购结果必须完全采用服务端返回。
- 含税与不含税值不得在同一公式相减；所有金额旁标明口径。
- `unavailable` 指标显示“暂无可靠口径”和原因，不显示 0。
- 卡券收入可进入规模和回款分析，但不进入 W15 的实际盈亏/利润贡献。
- `fundsReview=reviewed_only` 时，服务端必须按销售单复核状态整单纳入或整单排除；禁止按回款/开票行部分过滤后混入口径。
- `averageCollectionDays` 必须由服务端按已结清应收金额加权计算并返回样本数；前端不得改算。
- `exceptionCustomerCount` 仅统计期间内已形成正式异常/纠错对象或高风险待办的客户；普通协同提醒不得计入。

键盘与无障碍：

- Tab 顺序：期间/范围 → 覆盖口径 → 指标 → 图表维度 → 客户表 → 分页。
- 指标和图表选择使用按钮/单选语义及 `aria-pressed`；结果数量通过 `aria-live=polite` 播报。
- 图表提供“查看数据表”入口；图例有文字和数值，颜色不是唯一编码。
- 打开下钻页签后返回，焦点恢复到原指标、图形项或客户行。
- 数值读屏同时播报币种、含税/不含税和百分比含义。
