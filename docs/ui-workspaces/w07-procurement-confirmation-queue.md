## 1. 废止声明

采购二次确认不再是独立团队业务任务，也不再拥有独立队列页面。

| 原能力 | 目标合同下的唯一处置 |
| --- | --- |
| 作为销售单生效闸门的确认队列 | 收敛为 `SalesOrder` 已发布定义中的普通单人审批节点，在 W01 详情内通过或驳回 |
| 选择供应商供给、最新成本、供货数量、预计交期、履约方式 | 后移到销售单生效后创建采购单时录入 |
| `ProcurementConfirmation` 实体、状态机、驳回原因码 | 整体删除 |
| 「开始处理 / 退回团队」 | 随全系统责任池删除 |

`/procurement/confirm` 不得再作为有效处理入口。实现阶段删除对应队列页面后，该路由只允许重定向到 `/workspace` 或返回 404；不得保留第二套确认 UI。
