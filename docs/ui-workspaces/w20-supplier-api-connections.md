# W20 · API 供应商连接

> 状态：草稿
> 页面模式：M2 高密度查询列表 + M4 对象中心
> 主要路由：`/supplier-api/connections`、`/supplier-api/connections/:connectionId`
> 主要角色：采购、研发运维、系统管理员
> 最后更新：2026-08-01

## 1. 定位与目标

### 1.1 用户目标

- 采购能确认一个连接属于哪家供应商、计划承载哪些业务能力，以及业务能力是否已经具备可用条件。
- 研发运维能维护环境、适配器、地址配置引用和密钥引用，执行健康检查，并从同一连接上下文进入错误排查。
- 系统管理员能控制连接启停和接口权限，看清启停影响、能力状态、最近健康结果与目录同步水位。
- 所有角色都只能看到完成工作所需的安全元数据，任何页面、URL、日志或导出都不展示密钥正文。

### 1.2 业务目标

- 以 `supplier_api_connection` 作为稳定连接身份，以 `supplier_api_capability` 记录连接实际支持的统一能力。
- 供应商专用签名、鉴权、字段映射和错误由 Supplier Connector 隔离；商品、订单、结算和分析模块只依赖统一能力契约。
- 连接变更具备版本、幂等、健康验证和审计；故障、鉴权失败、限流和结果未知使用统一错误分类。
- 环境、供应商、连接和能力边界清晰，测试连接不能误触生产业务动作。

### 1.3 不在本工作面完成

- 不在 W20 映射外部商品、确认供给版本或审核供货价；进入 W21。
- 不在 W20 发布商城商品；进入 W22。
- 不在 W20 重放具体订单、退款或结算请求；业务对象进入 W26/W27，接口异常进入 W29。
- 不编辑供应商专用协议脚本，不允许业务模块直接填写任意请求模板绕过 Supplier Connector。
- 不输入、回显、复制或导出 API Key、Secret、私钥、签名材料和完整回调验签值。

## 2. 用户、权限与数据范围

### 2.1 角色分工

| 角色 | 默认入口 | 可见范围 | 主要动作 |
| --- | --- | --- | --- |
| 采购 | 连接列表“业务视图” | 被授权供应商及连接的业务摘要 | 选择供应商、确认业务能力需求、查看同步与供给入口 |
| 研发运维 | 连接列表“技术视图” | 被授权环境和连接；业务价格等仅按需要展示 | 维护适配器和安全配置引用、健康检查、查看技术错误 |
| 系统管理员 | 全部连接治理视图 | 被授权环境的连接、能力和接口权限 | 创建连接身份、启停连接、维护能力开关、查看审计 |
| 安全审计人员 | W19 链入只读中心 | 授权连接与配置变更事件 | 查看谁在何时绑定/轮换了引用；看不到密钥正文 |
| 运营/客服/财务 | 从关联对象只读查看 | 与本人业务对象相关的连接名称、可用性和能力摘要 | 无连接配置动作 |

### 2.2 权限与字段边界

| 情况 | W20 行为 |
| --- | --- |
| 无模块权限 | 不展示导航、命令和快捷入口；直接访问显示无权限页 |
| 有模块权限但无供应商/环境范围 | 展示“当前角色无连接数据范围”，不显示 0 连接 |
| 采购无技术配置权 | 显示“配置已绑定/待绑定”、健康结果和业务影响，不显示地址引用、密钥引用标识或适配器诊断 |
| 运维无采购业务权 | 可维护技术引用和执行健康检查；不能确认供给、成本或商品映射 |
| 无安全引用查看权 | 字段标签保留，只显示“已绑定/未绑定/需轮换”，引用别名与版本也隐藏 |
| 连接状态阻塞动作 | 动作原位禁用，显示服务端 `actionBlockers`；不得把能力不支持伪装成用户权限不足 |
| 权限在页签打开期间收回 | 清除引用元数据、诊断摘要和短时技术链接，转无权限/无范围状态 |

### 2.3 主责边界

- 采购主责供应商业务身份、计划能力和业务启用确认。
- 研发运维主责适配器、环境、地址配置引用、密钥管理系统引用、健康检查和故障排查。
- 系统管理员主责接口权限和连接启停治理，但不能代替采购确认供应关系或成本。
- Supplier Connector 负责把供应商协议转换为统一命令/事件；前端不展示也不允许编辑供应商专用鉴权逻辑。
- “确认业务能力需求”是连接/能力对象上的追加式业务确认：采购只能记录需求、适用范围和证据，不能写 `supplier_api_capability` 的启停状态。该动作不进入 W01/W02，也不创建、领取或完成 `work_item`。
- “配置能力”是系统管理员的独立对象动作；服务端分别校验连接版本和每条能力版本，不能把采购确认当作能力状态变更命令复用。

## 5. 展示内容与字段

### 5.1 连接身份与状态

| 区域 | 字段 | 用户文案 | 数据来源 | 口径 / 格式 | 权限规则 |
| --- | --- | --- | --- | --- | --- |
| 连接 | `connectionCode` | 连接代码 | `supplier_api_connection` | ERP 全局稳定唯一；环境不是唯一键组成部分 | 有连接查看权可见 |
| 连接 | `supplierId/name` | 供应商 | `supplier_account` | 稳定供应商身份 + 当前名称 | 按供应商数据范围 |
| 连接 | `environment` | 环境 | 连接 | 开发/测试/生产等固定枚举；生产用文字警示 | 按环境权限 |
| 连接 | `status` | 连接状态 | 连接 | 启用、停用、故障；文字 + tone | 服务端事实 |
| 连接 | `ownerBusiness/ownerTechnical` | 业务负责人 / 技术负责人 | 责任配置投影 | 分别展示，不用一个“负责人”混合责任 | 可见性按组织范围 |
| 连接 | `version` | 配置版本 | 连接 | 用于并发提交 | 有配置查看权可见 |
| 健康 | `lastHealthAt/result` | 最近健康检查 | 连接 + 健康任务 | 时间、成功/失败/部分能力失败 | 采购只看业务化摘要 |
| 健康 | `latencyMs` | 响应耗时 | 健康检查投影 | 毫秒/秒格式化，不作为 SLA 结论 | 技术角色可见 |
| 目录 | `catalogFreshness` | 商品目录水位 | `catalog_sync_job` 投影 | 最近成功时间、进行中/陈旧/失败 | 有 W21 查看权可钻取 |

### 5.2 能力与安全配置

| 字段 | 用户文案 | 数据来源 | 口径 / 格式 | 权限规则 |
| --- | --- | --- | --- | --- |
| `capabilityCode` | 能力 | `supplier_api_capability` | 商品、价格、库存、下单、查询、取消、退款、物流、回调、结算等固定代码映射 | 有连接查看权可见 |
| `capabilityStatus` | 能力状态 | 能力记录 | 启用/停用；不等同每个商品都可用 | 采购可见 |
| `constraintSnapshot` | 能力限制 | 能力记录 | 只展示已规范化安全摘要，如时段、频率、范围 | 不显示供应商协议秘密 |
| `verificationResult/At` | 最近验证 | 健康检查结果 | 按能力显示成功、失败、未验证、陈旧 | 技术详情按权限展开 |
| `adapterCode/version` | 适配器 / 版本 | Connector 注册表 | 固定部署产物身份 | 研发运维、管理员可见 |
| `endpointReferenceState` | 地址配置 | 连接安全配置 | 仅显示已绑定、引用别名/版本、需轮换 | 普通采购只看就绪状态 |
| `credentialReferenceState` | 密钥配置 | 连接安全配置 | **只显示已绑定、密钥管理引用安全别名和版本；绝不显示正文** | 仅授权技术角色可看别名/版本 |
| `rateLimitPolicy` | 限流策略 | 连接 | 规范化策略摘要 | 不显示可被滥用的内部细节 |
| `callbackVerificationState` | 回调验签 | Connector 健康投影 | 已配置/未配置、最近验证结果 | 不显示验签材料 |

业务列表、审计、错误详情和导出均不得返回密钥正文。即使技术角色需要轮换，也只能从服务端提供的密钥管理系统引用选择器选取不透明引用；W20 不提供秘密文本输入框。

### 5.3 统一错误摘要

| 错误类别 | W20 展示 | 下一步 |
| --- | --- | --- |
| 能力不支持 | 指明缺少的统一能力和业务影响 | 调整能力计划或转人工，不重试 |
| 参数/映射错误 | 标明数据问题，不显示原始敏感报文 | 进入 W21/W29 修复 |
| 供应商业务拒绝 | 展示安全业务原因 | 打开关联业务对象处理 |
| 网络超时/临时不可用 | 展示自动重试状态和最近查询结果 | 等待或进入 W29 |
| 结果未知 | 明确不能再次创建业务请求 | 查询原请求最终结果 |
| 鉴权/签名失败 | 高风险故障，自动重试已停止 | 告警并由运维检查引用/适配器 |
| 限流 | 展示退避到何时 | 等待系统重试 |
| 回调重复/乱序 | 展示已幂等忽略或拒绝倒退的摘要 | 通常无需人工；可审计 |

## 6. 搜索、筛选、排序与默认视图

| 能力 | 默认值 | URL 状态 | 行为 |
| --- | --- | --- | --- |
| 环境 | 生产 | `environment` | 不同环境数据、指标和选择完全隔离；切换清空行选择 |
| 状态 | 启用 + 故障 | `status` | 停用连接可单独查询 |

| 搜索 | 空 | `q` | 搜连接代码和供应商名称；不搜索引用或秘密 |
| 排序 | 故障优先，其次最近检查 | `sort` | 服务端稳定排序，不因轮询任意跳行 |

列表指标可点击并同步筛选摘要。1440×900 下页头、指标、工具栏和分页同时存在时至少显示 6–8 条连接；连接身份和行级主动作固定。

## 7. 操作契约

| 操作 | 入口 | 权限 / 前置条件 | 确认 | 成功结果 | 失败恢复 |
| --- | --- | --- | --- | --- | --- |
| 创建连接身份 | 列表主动作 | `CREATE_CONNECTION`；供应商和环境有效；代码唯一 | 展示供应商、环境、初始负责人 | 返回连接 ID、代码和“待配置”下一步 | 保留输入；同幂等键返回同一连接 |
| 编辑业务资料 | 概览 | 采购/管理员业务配置权；版本一致 | 展示字段 diff | 返回新配置版本和审计事件 | 冲突时打开 diff，不覆盖技术配置 |
| 确认业务能力需求 | 能力矩阵 | 采购负责该供应商；连接与能力版本一致；只填写业务需求与证据 | 展示需求能力、适用范围和商品影响 | 追加对象级业务确认，返回确认记录、对象版本和审计号；不改变能力状态，不创建/完成 `work_item` | 结果未知按原 `operationId` / 幂等键查询；对象版本冲突时重读 diff 后再确认 |
| 绑定/轮换地址引用 | 安全配置 | 研发运维技术配置权；只能选择服务端不透明引用 | 展示环境、引用安全别名、版本和影响 | 返回“已绑定”及新配置版本；不回显值 | 结果未知查询原请求；旧引用状态由服务端决定 |
| 绑定/轮换密钥引用 | 安全配置 | `MANAGE_CREDENTIAL_REFERENCE`；秘密已存在密钥管理系统 | 强确认生产环境、引用别名和轮换影响 | 返回引用已绑定、版本和审计号；**永不返回密钥正文** | 失败保留旧有效引用；不允许明文兜底 |
| 配置能力 | 能力矩阵 | 仅系统管理员有 `UPDATE_CAPABILITIES`；采购业务确认已完成；能力代码固定 | 显示启停能力与下游影响 | 返回新能力版本，需验证项标为未验证 | 组合约束失败时保留编辑并展示 blocker |
| 执行健康检查 | 页头/能力矩阵 | 技术检查权；基础引用已就绪 | 生产全能力检查显示不会创建业务订单 | 创建健康任务号；完成后固定结果 | 超时/未知按任务号查询，不盲目重复 |
| 启用连接 | 页头主动作 | 服务端全部前置满足；必要能力已验证 | 强确认环境、能力、下游商品/订单影响 | 状态变为启用，返回生效时间和审计号 | 结果未知保持原显示并查询最终状态 |
| 停用连接 | 页头更多 | `DISABLE_CONNECTION`；服务端返回活动业务 blocker | 展示受影响发布、待处理订单、同步任务和替代方案 | 状态停用；不删除连接、版本和历史业务 | 有活动 blocker 时拒绝并链到 W21/W26/W29 |
| 触发目录同步 | 目录同步区 | `CATALOG_SYNC` 能力启用且健康；有 W21 权限 | 展示连接、同步范围和外部水位 | 创建 `catalog_sync_job` 并打开 W21 进度 | 同来源批次幂等；未知时查询任务 |
| 打开错误中心 | 健康记录 | 有 W29 权限 | 无 | 定位连接和追踪号 | 无权时保留安全摘要和联系责任人 |

启停和能力配置只改变连接治理状态，不直接修改外部商品、供给、发布版本或历史订单。执行时服务端再次校验权限、连接版本、环境和业务 blocker。

- 所有查询由 TanStack Query 管理；Query Key 包含用户、角色、权限版本、环境、连接 ID、筛选和配置版本。
- 健康记录、同步水位和相关影响来自服务端投影，展示各自数据水位；列表轮询不得清空旧行。
- `safeReferences` 只能包含就绪状态和被批准展示的安全别名/版本，接口契约禁止返回密钥正文、可直接访问秘密的 URL 或存储路径。
- 能力限制返回规范化安全字段；供应商原始协议、签名串和完整报文不进入普通 UI 响应。

### 8.2 提交

```ts
type SupplierConnectionCommand = {
  connectionId: string
  action: "UPDATE_BUSINESS_PROFILE" | "BIND_ENDPOINT_REFERENCE" | "BIND_CREDENTIAL_REFERENCE" |
    "RUN_HEALTH_CHECK" | "ENABLE" | "DISABLE" | "START_CATALOG_SYNC"
  expectedVersion: string
  payloadReference?: string
  reasonCode?: string
  idempotencyKey: string
}

type ConfirmBusinessCapabilityRequirementCommand = {
  connectionId: string
  capabilityCode: string
  requirement: "REQUIRED" | "NOT_REQUIRED"
  applicabilityReference?: string
  evidenceReferences?: string[]
  reasonCode: string
  expectedConnectionVersion: string
  expectedCapabilityVersion: string
  operationId: string
  idempotencyKey: string
}

type ConfirmBusinessCapabilityRequirementResult = {
  outcome: "CONFIRMED" | "REJECTED" | "UNKNOWN"
  operationId: string
  confirmationId?: string
  confirmationVersion?: string
  connectionVersion?: string
  capabilityVersion?: string
  auditEventId?: string

type UpdateSupplierCapabilitiesCommand = {
  connectionId: string
  capabilityChanges: Array<{ code: string; enabled: boolean; constraintVersion?: string }>
  expectedConnectionVersion: string
  expectedCapabilityVersions: Record<string, string>
  reasonCode: string
  operationId: string
  idempotencyKey: string
}
```

- `payloadReference` 是服务端签发、短时、仅绑定用途的不透明引用，不能是用户输入的秘密正文。
- 配置表单使用 TanStack Form；服务端校验固定能力代码、引用权限、环境、版本和关联业务影响。
- `ConfirmBusinessCapabilityRequirementCommand` 只追加采购业务确认及审计事件；服务端同时校验 `expectedConnectionVersion`、`expectedCapabilityVersion` 和稳定 `operationId` / `idempotencyKey`，不得更新能力启停状态，也不得产生任何 W01/W02 任务生命周期。
- `UpdateSupplierCapabilitiesCommand` 仅接受系统管理员的 `UPDATE_CAPABILITIES` 权限；它独立校验连接/能力版本并追加配置审计，不能由采购角色提交，也不能把业务确认记录伪装成配置结果。
- 返回 `CONFIRMED | REJECTED | UNKNOWN`、对应对象新版本、后台任务号（仅健康检查/目录同步等异步动作）、审计编号和下一步。
- 正式结果不确定时不乐观启停、不切换引用显示；使用同一请求身份查询最终结果。
- 健康检查与目录同步返回后台任务，不把 HTTP 请求完成冒充业务检查完成。

### 8.3 前端边界

- 前端只格式化健康时间、耗时、能力和状态文案，不判断连接是否可用于下单。
- “可启用”“目录陈旧”“受影响对象数”和能力组合有效性全部来自服务端。
- 前端不生成签名、不保存密钥、不拼供应商 URL、不重试供应商业务命令。
- 能力声明表示连接支持，不表示所有商品支持；商品级能力由外部商品/供给/发布版本返回。
- 连接停用不允许前端修改历史订单、供给或发布快照。

## 9. 页面状态矩阵

| 状态 | 页面表现 | 可执行动作 | 恢复方式 |
| --- | --- | --- | --- |
| 初载 | 页头、指标、表格或中心锚点同尺寸 Skeleton | 应用壳导航可用 | 查询完成原位替换 |
| 刷新 | 保留连接与健康摘要，显示水位 | 查看和非冲突导航可用 | 成功更新；失败保留旧数据 |
| 无连接 | 区分“尚未接入”和筛选无结果 | 有权时新建或清除筛选 | 创建/清除后恢复 |
| 无数据范围 | 不显示 0 连接 | 查看当前供应商/环境范围 | 权限更新后重查 |
| 查询失败 | 无缓存显示 `BusinessFailureState`；有缓存保留连接并标陈旧 | 重试；陈旧配置只读 | 查询恢复 |
| 待配置 | 显示缺失步骤和 blocker，不显示成故障 | 完成业务/技术配置 | 前置满足后健康验证 |
| 健康检查中 | 固定任务号、范围和进度 | 查看旧结果；不重复执行同任务 | 查询任务完成 |
| 连接故障 | 高风险 Alert + 最近安全错误摘要 | 检查引用、健康检查、进入 W29 | 修复并验证成功 |
| 鉴权/签名失败 | 明确自动重试已停止，不显示秘密 | 轮换引用、联系运维 | 新引用验证成功 |
| 目录陈旧 | 连接状态与目录水位分开显示 | 触发同步或进入 W21/W29 | 同步追平 |
| 配置版本冲突 | `ConflictResolutionDialog` 展示安全字段 diff | 重新加载并审阅 | 基于最新版本提交 |
| 保存失败 | 保留表单和旧有效配置 | 同幂等键重试或放弃 | 成功/取消 |
| 正式动作成功 | `FormalActionResult` 固定展示连接 ID、对象版本、业务确认/配置/启停/轮换结果、审计号、时间和下一步 | 运行健康检查、进入 W21 | 用户明确关闭结果 |
| 正式结果不确定 | 不展示业务确认成功，不乐观改变能力、启停或引用状态 | 按原 `operationId` / 请求身份查询最终结果 | 得到最终结论 |
| 字段级隐藏 | 引用字段只显示就绪状态或完全掩码 | 其它有权动作 | 权限更新后重查 |
| 权限收回 | 清除引用元数据、诊断和技术链接 | 返回有权模块 | 权限恢复后重查 |

## 10. 响应式、键盘与无障碍

| 视口 | 布局变化 | 保留内容 | 允许降级 |
| --- | --- | --- | --- |
| 1440×900 | 侧栏展开；列表可开 768px detail；中心双栏 | 供应商、连接代码、环境、状态、健康、主动作 | 无 |

| 1024×768 | 侧栏图标模式；中心单主栏 + 侧卡；工具栏换行 | 环境、状态、引用就绪、健康结果 | 约束详情折叠 |
| 768×1024 | 导航抽屉；表格横向滚动，连接/操作固定；中心内容单列 | 只读连接、能力、健康与错误入口 | 技术记录改分段卡片 |

- Tab 顺序：页头动作 → 指标 → 工具栏 → 表格 → 中心锚点 → 当前区控件 → 正式动作。

- 能力矩阵用表头/行头语义，并播报启用、验证和商品级差异说明。
- 健康任务进度和结果通过 `aria-live=polite`；结果未知使用明确文字，不自动播报为失败。
- Dialog/Sheet 关闭后焦点回触发源；健康检查完成后焦点可留在原按钮，结果区被读屏播报。

## 11. 与其他工作面的关系

| 来源 / 去向 | Wxx | 携带上下文 | 返回规则 |
