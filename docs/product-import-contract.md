# 商品与供给导入合同

## 1. 文件与列序

使用 `.xlsx` 文件的「对内」工作表，第 1 行固定为以下 16 列。不得改表头、调换列序或删除选填列。

| 列 | 表头 | 填写要求 |
| --- | --- | --- |
| A | 产品编码 | 选填；同一商品多规格须使用相同编码，不得占用其他商品编号 |
| B | 产品条码 | 选填，文本格式 |
| C | 产品主图 | 选填，仅识别工作簿内 DISPIMG 图片引用 |
| D | 产品副图 | 选填，第一张副图 |
| E | 产品副图 | 选填，第二张副图 |
| F | 品牌 | 建议填写统一品牌名称 |
| G | 产品类别 | 必填，实物商品分类名称 |
| H | 产品名称 | 必填 |
| I | 产品规格 | 同一产品编码多规格时填写不同规格 |
| J | 供应商代发成本价（含税，元） | 必填，非负数，最多 4 位有效小数 |
| K | 供应商集采成本价（含税，元） | 必填，非负数，最多 4 位有效小数 |
| L | 供应商集采起订量 | 空白默认 1；填写时必须大于 0，最多 6 位有效小数 |
| M | 市场参考价（元） | 选填，最多 2 位有效小数 |
| N | 供应商编号 | 必填，按系统编号精确匹配已有供应商 |
| O | 供应商订货编码 | 必填，供应商侧对应本规格的 SKU 编码 |
| P | 进项税率（%） | 必填，0–100，最多 4 位有效小数；13 表示 13% |

每行代表一个商品规格与一条供应商供给。同一 SKU 可用不同行关联不同供应商，各行须使用相同产品编码和规格。文件容量、压缩包、XML、图片、最多 1000 行等限制继续执行第一期基线。

## 2. 写入规则

1. 必须先校验供应商编号、实物供给资格和供给创建权限。供应商未录入、已失去资格或权限不足时，该行失败，不自动创建供应商。
2. 同一产品编码归入同一 SPU，新规格追加 SKU。产品编码留空时沿用名称、规格与条码生成稳定导入编号的规则，不按相似名称合并。
3. 已有规格仍须处理供给，不得因商品已存在而跳过供给登记。规格与条码指向不同 SKU 时拒绝该行。
4. J、K、L 仅写入供应商供给条款。新建 SKU 的公司代发参考价、公司集采参考价及其取价门槛留空；已有 SKU 的售价保持不变。M 列用于新建 SKU 的市场参考价。
5. 新供给来源为 Excel，初始状态为可供，可供数量为 **999**；生效日期为导入当天，失效日期留空，配送模板跟随供应商默认模板。999 是供给可供数量，不是仓库库存，不创建入库单或库存余额。
6. 相同供应商订货编码已关联本 SKU 时复用供给，原成本价、起订量、税率、状态和可供数量均保持不变；结果必须提示已有数据未覆盖。该编码已关联其他 SKU 时，该行失败。
7. 商品、SKU、媒体资产登记、供给、商业条款、可供记录及业务审计在同一行事务内提交。任一步失败，回滚该行目录与供给写入，不影响其他行。媒体上传在事务外进行；品牌和分类沿用独立主数据匹配及建档流程。
8. 公司商品创建、编辑及供给创建继续执行各自的数据范围、维护责任与供应商资格检查，导入权限不得替代这些检查。

## 3. 旧任务与发布

1. 新提交仅接受 16 列模板。旧 13 列与 24 列文件须转换后提交，不能将历史公司售价直接改名为供应商成本。
2. 已提交的版本 1、2 行清单和旧源文件按原商品导入语义恢复，不自动建立供给，不设置可供数量。版本 3 清单保留新列序。
3. 发布时须更新全部导入执行实例后再开放新模板提交。存在 16 列任务时不得回滚到只识别旧模板的执行器；须先完成任务或停止执行并保留任务输入，再处理回滚。
4. 本次不修改已有供给数量，不批量回填 999，不变更持久化实体或索引。
