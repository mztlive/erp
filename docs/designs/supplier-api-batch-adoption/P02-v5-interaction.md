# P02 售价设置双栏交互合同

版本：V5 试行，规则表单修订。实施授权：2026-10-28 用户要求直接修改页面供查看。状态：待实际页面视觉与交互确认；不得登记为已验收。

## 1. 布局

1. 保持完整工作区宽度。宽屏使用左侧售价规则、右侧商品售价双栏；窄窗口依次展示规则和商品，不隐藏操作。
2. 顶部展示供应商、已选数量、批次信息及返回商品库入口。步骤之间显示连接线，当前步骤突出，先前步骤使用勾选标识。
3. 左侧依次展示售价选择、代发与集采规则、已有售价处理。图标用于分区识别；互斥选项使用单选控件，不使用重复的大图标按钮。
4. 底部保留保存状态、保存草稿和下一步。返回商品库继续执行未保存修改提示。

## 2. 规则输入

1. “要设置哪些售价”使用单选项：“只设置代发价／代发价和集采价相同／代发价和集采价分别设置”。同价显示一组规则，分别设置显示代发和集采两组。
2. 每组规则使用同一行的计算方式选择器与数值输入。方法显示“采购价 + 百分比／采购价 + 金额／指定售价／暂不设置”；参数标签分别为加价比例、加价金额、售价，并标明单位。不常驻展示操作引导、计算示例或重复解释。
3. 初次参数为空，不预填比例、金额或起订量。模式切换、不同规则统一、已有集采值保留或清空执行 V4 第 3 节。
4. 集采起订量置于集采规则内，同价时置于共用规则内；标明最低购买数量与公司基础单位。仅代发不展示该输入。
5. “已有售价处理”常驻展示“仅补空价／更新本批未入库项”。更新时提供“保留手动修改与清空”；允许覆盖人工调整时必须显示影响数量。已有公司 SKU 原价始终保留。
6. 预览区保留标题、数量、含税标识及分页，不常驻展示全量展示说明或核对步骤说明。异常、覆盖风险与模式切换确认继续按实际状态显示。

## 3. 商品反馈

1. 取消仅展示两项的限制。展示本批未排除商品，每页 8 项；不超过 8 项时全部展示。分页只切换展示范围，不影响规则作用范围或提交集合。
2. 修改规则后即时预览当前页售价，继续使用定点数计算与现有填值保护规则；最终金额以服务端核对为准。
3. 展示商品、规格、接口采购报价、公司代发价和公司集采价。空值需区分待设置、已清空、未设原价、缺少报价与本次不设置；已有 SKU 显示保留原价。
4. 单项编辑仍在核对入库步骤执行；本页不增加直接入库动作，不改变价格归属、采购能力、权限或后台任务契约。

## 4. 验收

1. 检查三种定价模式、三种计算方法、暂不设置、模式切换确认、人工保护、分页、保存与返回提示。
2. 检查宽屏双栏、窄窗口布局、键盘操作及四步进度连接线。静态检查不得代替实际页面验收。
