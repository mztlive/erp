# P02 批量售价简化交互合同

状态：用户已确认（2026-10-27）。适用图稿：P02 V4 同价状态与分别设置状态。本稿作为已确认的 P02 设计基线，替代 P02 V3 的布局与交互要求，不改变价格归属、计算精度及权限规则。

## 1. 默认作业面

1. 页面依次展示：供应商与已选 SKU 数量、步骤、定价方式、规则输入、集采门槛、两行价格预览、更多设置、底部操作。删除重复价格说明、重复计算基础控件和无异常时的警告条。
2. 定价方式使用三项直接可点的分段选择：仅代发、代发与集采同价、分别设置。默认呈现“代发与集采同价”的简洁布局；计算参数首次为空，不默认填入加价比例或起订量。图中的 15% 和 10 均为用户已填写的示例。
3. “代发与集采同价”只显示一套公司售价规则和一个公司集采起订量；仅代发模式隐藏集采规则与门槛。分别设置模式显示代发、集采两行规则，允许独立方法与参数。
4. 规则行使用紧凑表达：方法选择、基础价或金额、比例或金额输入。比例加价显示“接口采购报价 + 15%”；固定加额显示“接口采购报价 + 10 元”；指定金额显示“统一售价 99 元”。固定基础价只读文字展示，不重复渲染禁用输入框。
5. 保留现有“不设置”方法；不设置表示保留草稿值，不能等价于清空。参数变化即时更新可计算样例；权威批量计算与最终确认继续执行主合同。
6. 公司集采起订量按各 SKU 的公司基础单位解释，单位只提供静态说明；混合单位的具体值在逐项核对中展示。缺少有效起订量时显示字段错误，不能通过简化布局绕过成对校验。
7. 价格预览默认仅显示两项及其接口报价、公司代发价、公司集采价；已有公司 SKU 显示“保留原价”，不能显示会覆盖已有 SKU 的虚构结果。完整结果在核对页查看。

## 2. 低频设置与错误

1. “更多设置”默认折叠，摘要保持可见：“仅填空值 · 保留人工调整 · 已有 SKU 原价不变”。展开后编辑填值模式与是否保留人工调整；摘要必须随真实设置变化。
2. 涉及覆盖人工值的设置必须展开后明确选择，并显示影响数量。已有 SKU 原价保留是固定规则，不提供关闭选项。
3. 缺报价、价格异常、缺起订量等在对应字段或预览行显示，不在正常页面常驻多条告警。首次尚未填写时不立即显示全页错误。
4. 无来源集采能力不阻止填写公司集采参考价；相关商品在核对页持续显示“本供给仅支持代发”，不得用界面简化消除采购资格校验。

## 3. 模式切换

1. 从同价切换分别设置时，以当前共享规则初始化两行；已有单独设置草稿时恢复各自草稿，避免丢失修改。
2. 从分别设置切换同价时，若规则不同，显示紧凑确认，明确将以代发规则统一；取消则保持原模式。不得无提示覆盖集采规则。
3. 切换仅代发时，已填写的集采规则暂存但不参加本次规则计算；若本批草稿已有集采值，必须明确选择保留或清空本批可编辑项的集采价与门槛，不能静默删除或留下不可见的生效值。
4. 所有模式切换均保留单项人工例外的保护规则；恢复或统一计算不得自动覆盖已有公司 SKU。
