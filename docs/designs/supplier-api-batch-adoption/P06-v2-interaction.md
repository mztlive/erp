# P06 入库结果交互合同

版本：V2。实施授权：2026-10-29 用户要求调整结果页。状态：待实际页面视觉与交互验收。

## 1. 页面结构

1. 结果页按页头、结果反馈、入库明细排列；取消四步进度、草稿保存状态及底部固定操作栏。
2. 页头展示“入库结果”、供应商及批次信息。结果区突出成功数量和完成状态，操作紧邻结果；全部成功时提供“继续选品”和“刷新结果”。
3. 处理中显示后台进行状态；部分完成、未完成与结果待核实使用对应反馈。待核实项只查询原操作，其他待办进入待处理流程。不得把待核实、排除或跳过计为成功。
4. 仅展示非零分类数量。全部成功时不重复展示零值统计、总量说明、固定入库规则或无效筛选。

## 2. 入库明细

1. 默认展示商品与规格、公司代发价、公司集采价及起订量、入库结果、操作。接口采购报价和匹配信息可从列设置展开。
2. 成功项保留“查看商品”“查看供给”入口；待处理项保留异常原因及相应处理入口。操作列须完整可见，窄窗口允许表格内部滚动。
3. 结果明细以文字身份展示商品，不依赖来源缩略图；规格为主、商品名为次。单位推断、人工调整与异常原因保持可见。
4. 来源变化仅展示实际变化字段；报价按十进制值比较，格式差异不算变化。没有实际变化时不增加该列。
5. 状态单一且无原因时不展示筛选；已生效筛选必须保留清除入口。列设置、分页及模式切换隔离沿用共享表格能力。

## 3. 验收

1. 覆盖全部成功、部分成功、全部失败、仅跳过、仅排除、后台处理中及结果待核实。
2. 检查来源未变化、真实变化、金额精度格式变化、列显隐恢复、筛选清除、商品与供给入口、窄窗口和账号权限。
3. 静态检查与构建不得替代实际页面视觉、交互及后台执行验收。
