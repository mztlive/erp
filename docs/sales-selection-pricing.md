# 选品册客户售价合同

## 适用范围与权限

- 仅 `PENDING_PUBLISH`（待发布）选品册允许改价。准备中、已发布及后续状态必须拒绝改价。
- 改价使用 `sales_selection_booklet:maintain` 权限，并在写入事务内校验选品册责任范围。
- 价格仅写入本册当前准备批次的商品快照与陈列快照。禁止更新商品主数据、SKU 修订、供应商报价或其他选品册。

## 定价规则

- 单个编辑按 SKU 指定客户含税售价。同一 SKU 在本册各套餐及单品陈列中的售价必须一致。
- 统一加价覆盖当前批次商品池中的全部 SKU，包含当前筛选未展示或尚未进入套餐的 SKU。
- 百分比以 `10` 表示加价 `10%`。新售价 = 当前客户售价 ×（1 + 百分比 ÷ 100）；每个 SKU 按系统银行家舍入保留两位小数，再加总套餐售价。
- 客户售价和加价百分比必须大于零，输入最多两位小数。单个编辑允许降价；百分比操作只允许加价。
- 连续两次独立加价在上次保存的售价上继续计算。同一请求重试不得重复加价。
- 任一金额或套餐合计溢出时，整次拒绝并保留全部原价格。
- 改价保留商品身份、修订、图片、档位及套餐成员。改价后套餐合计允许偏离原档位目标；后续重生成按新售价及原档位规则搜索。
- 管理端卡片、表格和改单弹窗必须展示原价、当前客户售价及累计加价比例。原价取选品册引用的精确 SKU 修订中的售价；套餐原价为成员原价之和。禁止改用商品当前修订价格。
- 累计加价比例 =（当前客户售价 ÷ 原价 − 1）× 100%，保留两位小数。降价必须标注为降价；原修订或原价缺失时显示“未记录”，禁止用当前客户售价推算原价。
- 卡片和表格使用相同陈列、档位及缺图筛选和业务操作。表格必须支持价格对比、排序、分页、列设置、单个改价、删除及套餐按档重生成。

## 生命周期

- 同批次按档或整册重生成沿用调整后的商品池售价。
- “调整来源与档位并准备”成功后创建新批次，客户售价按最新商品价格重置；失败保留原批次与改价。该动作的弹窗必须说明价格重置。
- 复制选品册沿用被复制快照的客户售价。
- 发布时冻结客户售价；客户页面、额度校验、提交方案、商品明细及导出沿用该售价，不回读商品当前售价替换。
- 从按份采购方案创建销售单时，逐行带入方案冻结的客户含税售价与数量，并使用手动定价模式；销售可继续调整，保存沿用表单中的最终售价。

## 接口与并发

管理端使用 `POST /admin/sales-selection-books/{id}/prices`；`sales-selection-booklets` 为同义路径。

```json
{
  "expected_version": 3,
  "batch_id": "当前准备批次",
  "idempotency_key": "本次操作唯一键",
  "change": { "kind": "SINGLE", "sku_id": "商品身份", "price": "128.50" }
}
```

统一加价的 `change` 使用 `{ "kind": "MARKUP", "percent": "10.25" }`。金额、百分比必须传十进制字符串；禁止混合提交两种改价方式或额外字段。

- 请求必须携带当前册版本及批次。版本冲突、批次变化时拒绝，调用方刷新后重新确认。
- 商品不属于当前批次、批次商品池为空、非法状态或非法金额时返回业务校验错误。
- 同键同载荷返回当前册详情；同键异载荷拒绝。
- 商品池、陈列、套餐合计、册版本、幂等结果及改价成功审计必须在同一事务提交。改价与发布竞争同一册版本，失败必须整体回滚。
- 请求结果未知时，调用方锁定原载荷，使用同一键确认原操作，禁止另起加价请求。

## 兼容与回退

- 复用既有快照价格字段及集合，不新增数据库字段或索引，不要求数据迁移。
- 管理端陈列响应增加可选 `sku_id`；公开响应继续使用独立字段白名单，禁止新增内部身份暴露。
- 回退应用版本必须保留已保存的客户售价，不批量重置选品册价格。撤销一次改价应在发布前逐 SKU 保存目标售价；禁止用反向百分比推算原价。
