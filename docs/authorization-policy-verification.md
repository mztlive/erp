## 3. 已覆盖行为

1. JSON 未知字段、未知版本、定时绑定字段、未登记权限、重叠人员资源动作和不可配置动作均拒绝。
2. 同批新建角色、绑定及范围使用批次最终动作资格；同批撤销动作不能用旧权限通过范围校验。
3. 权限授予上限同时约束现有角色和目标角色；系统、停用、软删和缺失角色不能经配置恢复或分配。缺失实体的角色仍须核验其继承、权限和入向绑定；人员的非角色分组必须拒绝。
4. replace 空角色集合及空权限集合表达明确撤权；文件未列范围保持原值；清空追加范围保留业务的默认本人基础。
5. 相同目标配置无重复变更；追加项顺序、目标 ID 顺序及重复项不产生虚假差异；旧范围转换须明确确认；审核摘要绑定操作人、版本和目标事实。
6. 普通显式配置导出后重新编译保持授权；无已保存配置的有效动作导出空追加范围，重新应用能够撤销导出后新增的追加范围。仓储空范围不生成本人授权，任务和来源继承动作不生成独立范围；复杂旧范围和缺少当前动作资格的休眠范围拒绝导出。
7. 回执规则接受同操作人、同键、同载荷重放；异载荷、异操作人或损坏回执拒绝。该覆盖为回执实体规则，不代表数据库提交或回滚已经验证。
8. CLI 验证计划原样提交、Token 传递、较大审核文件、0600 文件权限、不覆盖已有文件、导出再预览、必填参数、缺少凭证、403、禁止重定向以及无法解析响应时保留未知提交语义。成功响应缺少 data、回执字段或返回 null 时，apply 必须失败并报告提交状态未知。
