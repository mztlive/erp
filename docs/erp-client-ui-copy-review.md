# ERP 前端用户可见中文文案审查报告（A/B/C 三类问题）

- 分级：
  - **A 冗余**：整段多余、与标题/周边重复。
  - **B 车轱辘话**：口语化绕口、指令式口令、跨文件复制粘贴的重复句。
  - **C 技术名词/内部术语**：数据库表名、枚举原文、URL 参数、接口名、内部任务代号直接出现在用户文案中。
