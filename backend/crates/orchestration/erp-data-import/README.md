# erp-data-import

本 crate 执行商品、供应商、合同及历史数据导入，持有任务认领、不可变来源缓存和分片预算。应用必须注入已配置领域 Port 的服务及工作项授权提供者；导入代码不得依赖应用入口或旧 `erp-processes`。

商品导入必须先准备外部媒体，再在原事务执行供应商资格、商品变更、供给与审计。供应商导入必须沿用原逐行幂等身份，超时只标记待核对。合同识别必须位于归档事务之外，确认时重新校验客户与合同范围。来源缓存不得保存任务状态或授权结论。

库测试随业务实现维护。执行验收仅允许内联库单元测试，不执行 ignored 测试、集成测试、真实数据库或供应商服务。
